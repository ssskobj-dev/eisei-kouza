# 自前検定のシラバス（案）

この文書は案です。サイトには載りません。名前、問題数、合格の基準は、どれも仮の値です。

## 位置づけ

基準にしたのは、サテライトデータビジネス検定のシラバス（2026年1月20日版）です。この検定は6科目で、目標はすべて「説明できる」です。知識を問う入門の検定と読めます。

自前の検定は、その上に2段を置きます。

| | 基準にした検定 | 自前検定 上級（仮：Professional） | 自前検定 最上級（仮：Expert） |
|---|---|---|---|
| 問うこと | 説明できる | 判断できる | 設計し、発注できる |
| 想定する人 | これから学ぶ人 | 提案や企画で衛星データを扱う人 | 仕様を書き、事業者を選び、結果に責任を持つ人 |
| 問題の形 | 用語と概要 | 場面を示し、選ばせる | 資料を読ませ、書かせる |
| 例 | SARとは何か | この場面で光学とSARのどちらを使うか、理由は何か | この提案書の弱点を3つ挙げ、仕様書の要求事項に直す |

既存の検定と競わず、「合格した人が次に受ける検定」として置きます。既存の検定の主催者とは関係のない、独立した検定です。

## 上級（仮：Professional）

### 対象と前提

- コンサルタント、自治体やインフラ会社の担当者、測量や建設コンサルタントの技術者
- 前提：基準にした検定の範囲の知識（受験の条件にはしない）

### 形式（仮）

- 四肢択一 60問、90分。うち20問は、場面を示すケース問題
- 合格の基準：全体で70%以上、かつ科目ごとに50%以上
- オンラインで受験。問題は、受験者ごとに問題群から選んで出す

### 科目と目標

| 科目 | 目標（〜を判断できる） | キーワード |
|---|---|---|
| 1. センサーの選択 | 目的と条件から、光学、SAR、熱赤外、海色、大気のどれを使うかを選べる | 波長帯、偏波、Cバンド・Lバンド・Xバンド、昼夜と雲、植生の透過、入射角 |
| 2. 分解能と頻度の限界 | 対象の大きさと変化の速さから、足りる分解能と撮影の間隔を見積もれる | 空間分解能、画素と対象の大きさ、回帰日数、コンステレーション、新規撮像とアーカイブ、撮像の待ち時間 |
| 3. 解析手法の対応 | ユースケースに合う解析手法を選び、苦手な条件を挙げられる | 前後比較、干渉SAR、コヒーレンス、植生指数、時系列、機械学習による分類、物体検出、水色、気柱量 |
| 4. 結果の読み方 | 解析結果の図と数字を読み、言えることと言えないことを分けられる | 視線方向の変位、誤検出と見逃し、検出率、精度の条件、現地確認、参照データ |
| 5. データの調達 | 無償と有償のデータの違い、処理レベル、ライセンスの条件を踏まえて選べる | 無償データ、処理レベル、オルソ補正、利用許諾、二次利用、関心領域、最小発注面積 |
| 6. 費用と効果 | どこに費用がかかるかを分け、公表されている事例から効果の根拠を示せる | データ費、解析費、現地確認、初期と継続、実証と本格運用、費用の出どころ |
| 7. 制度と法律 | 衛星リモートセンシング法などが、調達と利用にどう関わるかを判断できる | 衛星リモートセンシング法、分解能の区分、データの取扱い、国の調達の方針 |
| 8. 分野別の実務 | インフラ、防災、農業、環境の代表的な使い方で、落とし所を選べる | 絞り込み、併用、定期監視、変化を見る、言えないことの明示 |

### 出題例

> ある県が、道路ののり面の点検で「見に行く順番」を決めたい。対象は山間部の延長80kmで、のり面は草木に覆われている。最も適切な方針はどれか。
>
> 1. 高分解能の光学画像を毎月撮り、目視で変状を探す
> 2. LバンドSARの干渉解析で動きのある箇所を拾い、上位を現地で確かめる
> 3. CバンドSARの強度画像を災害の前後で比べる
> 4. 熱赤外の画像で、のり面の温度のむらを見る

ねらい：植生とバンドの関係、衛星は「絞り込み」に使うという落とし所。

## 最上級（仮：Expert）

### 対象と前提

- 仕様書を書く人、事業者を選ぶ人、解析結果を説明する責任を持つ人
- 前提：上級の合格

### 形式（仮）

- 第1部：四肢択一 40問、60分（計算と読み取りを含む）
- 第2部：記述 3題、120分。資料（提案書の抜粋、解析結果の図、公的な手引きの抜粋）を読んで答える
- 合格の基準：第1部70%以上、かつ第2部は採点の基準で60%以上
- 第2部は、採点の基準を公開し、人が採点する。監修者が抜き取りで確かめる

### 科目と目標

| 科目 | 目標（〜を設計できる、評価できる） | キーワード |
|---|---|---|
| 1. 要求の定義 | 業務の問いを、対象、範囲、頻度、精度、納期の要求に直せる | 判断の単位、許容できる見逃しと誤検出、納期、更新の間隔、成果物の形式 |
| 2. 観測の設計 | 軌道、入射角、偏波、撮影の時期を踏まえ、観測の計画の妥当性を評価できる | 上り下りの軌道、レイオーバーとシャドウ、視線方向と斜面の向き、季節と積雪、基線 |
| 3. 精度の検証 | 検証の方法を設計し、事業者の示す精度の条件を読み解ける | 参照データ、抜き取り、混同行列、適合率と再現率、標準偏差、GNSSや水準測量との比較 |
| 4. 仕様書と調達 | 仕様書の要求事項を書き、提案を比べる基準を作れる | 要求事項、検収の条件、追加費用の条件、データの権利、再委託、撮像の失敗時の扱い |
| 5. 費用の見積もり | 前提を置いて費用を概算し、費用対効果を説明できる | 仮定の明示、単価の出どころ、面積と頻度、現地確認の削減、感度 |
| 6. 限界とリスクの説明 | 技術的、物理的な限界を、発注者と住民に誤解なく説明できる | 言えないことの明示、不確かさ、誤解されやすい表現、責任の分担 |
| 7. 複数データの統合 | 衛星、ドローン、地上の計測、台帳を組み合わせる設計ができる | 併用、役割の分担、データフュージョン、位置合わせ、更新の頻度の差 |
| 8. 法律、契約、倫理 | 法律、利用許諾、安全保障、個人情報の観点で、利用の可否を判断できる | 衛星リモートセンシング法、利用許諾、輸出管理、プライバシー、監視への懸念 |

### 出題例（記述）

> 資料A（事業者の提案書の抜粋）は、「衛星SARで市内全域の地盤沈下をミリ単位で監視できる」としている。資料B（解析結果の図）と資料C（公的な手引きの抜粋）を読み、次に答えよ。
>
> 1. 資料Aの記述のうち、条件を確かめるべき点を3つ挙げ、理由を書け
> 2. それぞれを、仕様書の要求事項の文に直せ
> 3. 検収のときに行う検証の方法を、費用の小さい順に2つ書け

採点の基準（例）：視線方向の変位であること、測れない場所があること、精度の条件（点の密度、期間、参照との比較）に触れているか。

## 問題の作り方と質の管理

- 問題は、サイトの記事（ユースケース、講座の章）と、その出典から作る。出典のない事実は問わない
- 1問ごとに、根拠の記事と出典、ねらい、難しさの見込みを記録する
- 受験の結果から、正答率と、上位と下位の受験者の差を問題ごとに出す。正答率が極端な問題と、差の出ない問題は見直す
- 変わりやすい値（衛星の機数、料金、制度）は、試験の基準日を決め、その時点の公的資料で問う
- 問題は公開しない。出題例だけを公開する

## 決めること

| 項目 | 内容 |
|---|---|
| 名前 | 検定の正式な名前と、2つの級の呼び方 |
| 主催 | Spacify合同会社の名前で行うか。監修の5名の関わり方（問題の確認、記述の採点） |
| 受験料 | 金額と、支払いの方法 |
| 合格証 | 形式（PDF、番号、有効期限の有無）と、合格者の名前の公開の有無 |
| 不正への備え | オンライン受験では、他人の手助けや検索を防ぎきれない。時間の制限、問題の入れ替え、記述の比重で弱めることはできる。最上級を会場やビデオ通話での受験にする案もある |
| 既存の検定との関係 | 独立した検定であることを、案内に明記する |
