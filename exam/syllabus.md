# 自前検定のシラバス（案）第2版

版の日付：2026年10月14日。この文書は作業用の案です。公開版は `cert.qmd`（資格のページ）で、名前は「衛星データマーケッター」「衛星データ解析エンジニア」に決まりました。問題数と合格の基準は、公開版の「予定」に揃えています。

第1版からの主な変更は、末尾の「第1版から直したこと」にまとめています。

## 位置づけ

衛星データの入門の検定は、用語と概要を「説明できる」ことを問うものが中心です（シラバスを作るときに、サテライトデータビジネス検定の2026年1月20日版の科目を参考にしました）。

この検定が問うのは、別の力です。場面を示され、どの衛星と手法を使うか、結果から何が言えて何が言えないかを「判断できる」ことです。入門の検定と競うものではなく、上下の関係もありません。既存の検定の主催者とは関係のない、独立した検定です。

想定する人は、解析を自分でする人ではなく、結果を読み、提案し、発注する人です。

## 始め方

2つの級を同時には始めません。受験者が分かれ、問題も足りなくなるためです。

| 段階 | 内容 | 始める条件 |
|---|---|---|
| 1 | 上級（仮：Professional）を始める | 下の「問題の材料」の条件を満たしたとき |
| 2 | 最上級（仮：Expert）を始める | 上級の合格者が一定数に達し、記述の採点の手順を試し終えたとき |

## 上級（仮：Professional）

### 対象

コンサルタント、自治体やインフラ会社の担当者、測量や建設コンサルタントの技術者、営業や企画の担当者。受験の条件はありません。

### 形式（仮）

- 四肢択一 60問、90分。4つの分野から15問ずつ。各分野の5問は、場面を示すケース問題
- 合格の基準：全体で70%以上（42問）。分野ごとの足切りは置かない
- 結果には、分野ごとの正答数も示す（合否には使わない）
- オンラインで受験。受験者ごとに、問題群から選んで出す
- 合格の有効期限：2年。技術と制度が変わるため

第1版では8科目それぞれに足切りを置いていましたが、1科目が7〜8問では、2〜3問の偶然で合否が変わります。4分野にまとめ、足切りをやめました。

### 分野と目標

| 分野 | 目標（〜を判断できる） | 含む内容 | キーワード |
|---|---|---|---|
| A. 衛星と手法を選ぶ | 目的と条件から、使う衛星と解析手法を選び、苦手な条件を挙げられる | センサーの選択、分解能と頻度の限界、解析手法の対応 | 光学とSAR、波長帯、昼夜と雲、植生、空間分解能、撮影の間隔、前後比較、干渉SAR、植生指数、分類、物体検出 |
| B. 結果を読む | 解析結果の図と数字から、言えることと言えないことを分けられる | 結果の読み方、精度の条件、現地確認の役割 | 視線方向の変位、誤検出と見逃し、精度の条件、参照データ、現地確認、言えないことの明示 |
| C. 調達と費用 | データと解析をどう手に入れ、どこに費用がかかるかを判断できる | 無償と有償のデータ、処理レベル、利用の条件、費用の内訳、制度 | 無償データ、新規撮像とアーカイブ、処理レベル、利用許諾、データ費と解析費、実証と本格運用、国の調達の方針 |
| D. 市場と提案 | 分野ごとの使われ方と段階を踏まえ、顧客への提案の筋を選べる | 分野別の事例、市場と政策の動き、落とし所、提案で避ける言い方 | 絞り込み、併用、定期監視、実証か本格運用か、費用の出どころ、普及の壁 |

制度と法律は、分野Cの一部として、公的な資料で確かめられる範囲だけを問います。第1版に書いた「分解能の区分」「輸出管理」は、出典を確かめていなかったので外しました。法律を扱う記事を作るときに、条文と公的な解説で確かめてから戻します。

### 出題例

> ある県が、道路ののり面の点検で「見に行く順番」を決めたい。対象は山間部の路線で、のり面は草木に覆われている。最も適切な方針はどれか。
>
> 1. 高分解能の光学画像を毎月撮り、目視で変状を探す
> 2. LバンドSARの干渉解析で動きのある箇所を拾い、上位を現地で確かめる
> 3. CバンドSARの強度画像を災害の前後で比べる
> 4. 熱赤外の画像で、のり面の温度のむらを見る

分野A。ねらい：植生とバンドの関係、衛星は「絞り込み」に使うという落とし所。根拠：講座の章「道路のり面と斜面」と、その出典。

## 最上級（仮：Expert）

### 対象

仕様書を書く人、事業者の提案を比べる人、解析結果を説明する責任を持つ人。前提は上級の合格です。

### 形式（仮）

- 第1部：四肢択一 40問、60分（読み取りと、前提を置いた概算を含む）
- 第2部：記述 3題、120分。資料（提案書の抜粋、解析結果の図、公的な手引きの抜粋）を読んで答える
- 合格の基準：第1部70%以上、かつ第2部は採点の基準で60%以上
- 合格の有効期限：2年

### 第2部の採点

人がすべてを採点する形は、運営の負担が大きく、続きません。次の手順にします。

1. 問題ごとに、採点の基準を先に決めて公開する（触れるべき点と、点の配分）
2. 基準に沿って、AIが一次採点をする。触れた点と、その根拠にした答案の箇所を記録する
3. 監修者が、合否の境目に近い答案の全部と、それ以外から抜き取った答案を確かめる
4. 受験者は、採点の記録を見て、異議を申し立てられる。異議は監修者が見る

AIの採点には誤りがあります。始める前に、同じ答案を監修者とAIが別々に採点し、ずれの大きさを確かめます。ずれが大きければ、記述を短答（要点を1〜2文で書く形）に変えます。

### 分野と目標

| 分野 | 目標（〜を評価できる、書ける） | キーワード |
|---|---|---|
| A. 要求の定義 | 業務の問いを、対象、範囲、頻度、精度、納期の要求に直せる | 判断の単位、許容できる見逃しと誤検出、更新の間隔、成果物の形式 |
| B. 提案の評価 | 事業者の提案の観測条件と精度の説明が、目的に合うかを評価できる | 撮影の向きと斜面の向き、測れない場所、季節と積雪、精度の条件、参照データとの比較 |
| C. 仕様書と検収 | 仕様書の要求事項と、検収の方法を書ける | 要求事項、検収の条件、抜き取りの確認、追加費用の条件、データの権利 |
| D. 費用と効果の説明 | 前提を置いて費用を概算し、効果と限界を発注者に説明できる | 仮定の明示、単価の出どころ、現地確認の削減、不確かさ、誤解されやすい表現 |
| E. 提案の組み立て | 市場と政策の動きを踏まえ、顧客に合う導入の段取りを組める | 小さく試す、併用、財源、実証から本格運用へ、他の手段との比較 |

第1版の「観測の設計」（軌道、基線など）は、解析をする人向けの内容でした。この検定の対象は発注する側なので、「設計する」ではなく「提案を評価する」に変え、分野Bにまとめました。

### 出題例（記述）

> 資料A（事業者の提案書の抜粋）は、「衛星SARで市内全域の地盤沈下をミリ単位で監視できる」としている。資料B（解析結果の図）と資料C（公的な手引きの抜粋）を読み、次に答えよ。
>
> 1. 資料Aの記述のうち、条件を確かめるべき点を3つ挙げ、理由を書け
> 2. それぞれを、仕様書の要求事項の文に直せ
> 3. 検収のときに行う検証の方法を、費用の小さい順に2つ書け

採点の基準（例）：視線方向の変位であること、測れない場所があること、精度の条件（点の密度、期間、参照との比較）に触れているか。各3点、要求事項の文として成り立っているかで各2点。

## 実施の形

参考にした検定の試験概要（公式サイト、2026年10月に確認）と比べて、実施の形を決めます。

| 項目 | 参考にした検定 | この検定の上級（案） | 考え方 |
|---|---|---|---|
| 方式 | 自宅などで受けるオンライン試験（外部の試験サービスを利用） | 同じく、自宅などで受けるオンライン試験 | 対象が働く人なので、会場には集めない |
| 時間と問題数 | 60分、50問程度、多肢選択 | 90分、60問、四肢択一 | 場面を読む問題が入るので、1問あたりの時間を長くとる |
| 受検の資格 | なし | なし | |
| 日程 | 期間を決めて実施。次回は未定と告知 | いつでも受けられる形を目指す | 受けたいときに受けられることを、違いにする。問題の入れ替えが前提になる |
| 再受検 | 同じ期間の中では不可 | 不合格のあと、一定の日数をあけて可 | いつでも受けられる形では、問題を覚えての再受検を防ぐ決まりが要る |
| 結果 | 決まった日に、受検者のページで発表 | 択一はその場で採点し、分野ごとの正答数と、間違えた問題の解説を返す | すぐに返すほうが学びになる。問題そのものは公開しない |
| 解説 | 合格発表の日に、オンラインの解説イベント | 間違えた問題ごとに、根拠の記事へのリンクを返す | 人が登壇しなくても回る形にする |
| 合格の証明 | 合格証と、オープンバッジ | 合格証（PDF、番号つき）。番号で本物かを確かめられるページ | オープンバッジは、発行の費用を確かめてから決める |
| 合格者の集まり | 合格者だけのオンラインの集まり | 始めの段階では作らない | 運営に人手がかかるため |
| 学ぶ材料 | 参考図書3冊と資料の一覧 | このサイトの記事（分野ごとに対応する記事の一覧を出す） | 出題の根拠を、すべてサイトの記事にそろえる |
| 決まりごと | 受検の規約、個人情報の扱い、販売の表記、動作環境 | 同じものを用意する | 受検の規約と動作環境は、まだ作っていない |

参考にした検定は、宇宙機関や大学が協力して作られています。この検定には、そうした後ろ盾はありません。信頼は、出題の根拠を公開すること、採点の基準を公開すること、監修者の確認の3つで作ります。

受検料は、参考にした検定の公表額を見たうえで別に決めます（金額の比較は、この文書には書きません）。

### 実施の方針：費用のかかる試験サービスは使わない

外部の試験サービス（本人の確認、監視、決済をまとめて扱うもの）は使いません。無料の道具でできる範囲で行います。そのぶん、次のように割り切ります。

- 本人の確認と監視は行わない。合格証に「オンラインで、監視なしで受験」と明記する
- 制限時間は、開始と提出の時刻の記録で確かめる。超えた答案は採点しない
- 問題の入れ替えは、あらかじめ作った複数の問題セットを順に使う形にする
- 用意するもの：受検の規約（不正をしたときの扱い、問題を外に出さない約束）、合格証の番号を確かめるページ

監視がないので、合格は「厳密な能力の証明」ではなく「この範囲を学び終えたことの確認」として案内します。

## 問題の材料

問題は、サイトの記事と、その出典から作ります。出典のない事実は問いません。そのため、記事が足りないうちは検定を始められません。

上級は、受験者ごとに問題を入れ替えるために、出題数の3倍（180問）を用意します。1本の記事から作れる問題を3〜4問と見ると、分野ごとに12〜15本の記事が要ります。

| 分野 | 要る問題数 | 材料になる記事 | 今ある本数（2026年10月13日） | 足りないもの |
|---|---|---|---|---|
| A. 衛星と手法を選ぶ | 45 | 講座の基礎の章、Sentinelの早見表、ユースケースの「限界」 | 早見表1、ユースケース4 | 基礎の章4本（強みと限界、光学とSAR、ほか） |
| B. 結果を読む | 45 | 講座のユースケースの章、ケース問題 | 章1、ケース問題1 | 講座の章を10本以上 |
| C. 調達と費用 | 45 | 講座の実務の章（調達、費用、仕様書）、ユースケースの「費用の考え方」 | ユースケース4 | 調達と制度の章が0本。最優先 |
| D. 市場と提案 | 45 | 市場ガイド、ユースケースの「コンサルタントへの示唆」 | 市場ガイド1、ユースケース4 | 市場ガイドを10本以上 |

始める条件は、4分野とも45問がそろい、監修者の確認が済むことです。毎朝の自動作成の順番を、足りない分野の記事を先に書くように変えると、早くそろいます。

## 問題の質の管理

- 1問ごとに、根拠の記事と出典、分野、ねらいを記録する
- 始める前：監修者が全問を確かめる。答えが1つに決まるか、出典と合っているか、古くなっていないか
- 始めた後：受験者から「この問題はおかしい」という報告を受け付け、監修者が見る
- 正答率などの統計は、1問あたりの受験者が100人を超えてから使う。それまでは、数字で問題の良し悪しを決めない。受験者が少ないうちは、統計は当てにならないため
- 変わりやすい値（衛星の機数、制度）は、試験の基準日を決め、その時点の公的資料で問う。記事が直されたら、対応する問題も見直す
- 問題は公開しない。出題例と採点の基準だけを公開する

## 決めること

| 項目 | 内容 |
|---|---|
| 名前 | 検定の正式な名前と、級の呼び方。既存の検定と紛らわしくない名前にする |
| 主催 | Spacify合同会社の名前で行うか。監修の5名の役割（問題の確認、記述の抜き取り、異議への対応） |
| 受験料 | 金額と、支払いの方法。有料登録に含めるか、別にするか |
| 合格証 | 形式（PDF、番号）、合格者の名前の公開の有無 |
| 対策講座との関係 | 既存の検定の対策講座と、自前の検定を、同じ場で扱う。案内では、2つが別の主催であることをはっきり書く |

## 第1版から直したこと

| 第1版の問題 | 直したこと |
|---|---|
| 問題を作る材料が足りない | 分野ごとに、要る問題数、材料になる記事、今の本数を書いた。始める条件を「4分野とも45問」にした |
| 科目ごとの足切りが不公平 | 8科目を4分野にまとめ、足切りをやめた |
| 記述を人が採点する前提だった | 採点の基準の公開、AIの一次採点、監修者の抜き取り、異議の受付の手順にした。始める前に、ずれを確かめる |
| 想定する人とずれた科目があった | 最上級の「観測の設計」を「提案の評価」に変えた。両方の級に「市場と提案」を加えた |
| 統計で質を管理する前提だった | 監修者の確認を主にし、統計は1問あたり100人を超えてからとした |
| 法律のキーワードが未確認 | 確かめていないキーワードを外した |
| 有効期限と版の日付がない | 有効期限を2年とし、版の日付を入れた |
| 2つの級を同時に始める | 上級を先に始め、最上級は条件がそろってからとした |
| 既存の検定の「上」に置く書き方 | 上下の関係ではなく、問う力が違う独立した検定と書いた |
