# 農地パトロールの現地調査を衛星データの自動判別で98%減らす：舞鶴市の約67,000筆から約1,500筆へ：農地調査を「衛星の自動判別、画面での目視、現地」の3段階に分ける使い方と、公表されている参考価格

（noteに貼る全文。全部を公開する。図は、サイトの記事の図を使う）

## この記事で分かること

- 農地の利用状況調査（農地パトロール）で、衛星の自動判別と人の目視をどう分担させるか
- 舞鶴市の「約67,000筆から約1,500筆へ」[1]という数字の中身と、ほかの自治体にそのまま当てはめられない理由
- 公表されている参考価格と、自治体の側に残る費用

## どんな使い方か

市町村の農業委員会は、農地法にもとづいて、毎年、区域内の農地が耕作されているかを調べます。利用状況調査、通称「農地パトロール」です。以前は、すべての農地を道路から目で見て回る方式でした。農地が数万筆ある市では、調査員の時間の多くが移動と記録に消えます。筆（ひつ）は、登記上の土地の1区画のことです。

農林水産省は、中山間地域等直接支払交付金や多面的機能支払交付金の現地確認も含めて、衛星画像で現地確認を省力化する取り組みを進めています。民間事業者のサービスを「衛星活用サービス集」にまとめ、自治体に紹介しています[5]。

この記事の使い方は、その中の1つです。衛星データの解析で「耕作されている」と判定できる農地を自動で分け、残りを光学画像の目視で判定し、それでも分からない農地だけ現地に行きます[1]。衛星が全部を決めるのではなく、現地に行く農地を3段階で絞る構えです。

## 事例：ニュージャパンナレッジ「衛星データを活用した農地現地確認効率化システム」

農林水産省の「衛星活用サービス集」に載っている事例です[1]。山口県の事業者が提供し、同じサービス集に載っている一般財団法人リモート・センシング技術センター（RESTEC）と開発したと、取材記事にあります[4]。

- 対応する制度は、中山間地域等直接支払交付金、多面的機能支払交付金、農地利用状況調査（農地パトロール）の3つです[1]
- 導入実績は山口県宇部市と京都府舞鶴市、実証は山口県内の18市町村です[1]
- 舞鶴市の農地パトロールでは、農地の70%を衛星データの解析で自動判別し、光学画像の目視判定と合わせて、現地調査を98%減らしました。筆数は約67,000筆から約1,500筆です[1]
- 宇部市では2023年度から本格運用しています。農地は約5万筆で、一次判定で現地確認が要るとされたのは約20%、最終的に現地で目視するのは全体の約2%です[4]

実証ではなく、導入実績として掲載されています。ただし、サービス集は事業者の回答を載せたもので、削減の数字は事業者の申告値です。舞鶴市の数字が、どの年度の調査かは書かれていません[1]。

使う衛星の名前は、このサービスのページにはありません[1]。同じサービス集でRESTECが載せている山口県の事例の図には、ALOS-2（だいち2号）とSentinel-2の名前があり、「SAR衛星画像の特徴」という説明が付いています[2]。合成開口レーダ（SAR）は、電波を使って雲があっても地表を観測する方式です。宇部市の取材記事では、目視に使うのは分解能約1mの光学画像で、毎年5〜6月の撮影分を処理するとあります[4]。

## 2026年時点の限界

（ここに図：limits　この使い方の5つの限界）

**技術的な限界**

- **自動判別できるのは約7割。** 舞鶴市の例では、農地の70%が衛星データの解析で自動判別され、残りは光学画像を人が目で見て判定しています[1]。衛星の解析だけで調査が終わるわけではありません
- **目視には、細かく見える画像が要る。** 宇部市では目視判定のために分解能約1mの画像を使っています。分解能の低い安価な画像では目視が要る農地が増え、省力の効果が薄れると取材記事は指摘しています[4]
- **狭い農地、果樹園、茶畑は判定しにくい。** 農林水産省の資料では、狭小な農地は衛星での判定が難しく現地の見回りが要る傾向があり、果樹園と茶畑は衛星画像で判別がつきにくいとされています。ごく小さな区画は「解析対象外」になる例があります[3]
- **画像は年1回の撮影が基本。** 宇部市は毎年5〜6月の撮影分を使います[4]。撮影の後に耕作をやめた農地や、天候で画像が更新されない年のことは、画像からは分かりません[3]

**衛星では決まらないこと**

- **畦畔や水路の機能は分からない。** 農林水産省の資料では、田の畦畔やかんがい機能は衛星解析で直接判定しにくく、水稲の作付けや水張りから田と判定する例が多いとされています[3]
- **「遊休農地」の判断は人が行う。** 衛星が出すのは、耕作されているように見えるかどうかです。遊休農地とするか、利用意向を聞くかは、農業委員会の判断として残ります
- **98%は1市の結果。** 削減率は、農地の形、作物、画像の分解能、前年の結果の蓄積で変わります。宇部市でも、衛星判定の蓄積が増えるほど調査数を減らせるとされています[4]。初年度から同じ数字が出るとは限りません

## （仮）自社の業務に入れるなら

市町村の農業委員会の事務局に入れる場合を想定した例です。

（ここに図：flow　農地パトロールを3段階に分ける手順）

1. 農地の区画データ（ポリゴン）と台帳の地番をそろえる
2. 衛星データの解析で、耕作されている農地を自動判別する
3. 自動判別できなかった農地を、光学画像で画面上で目視する
4. 要調査の筆だけ、タブレットで現在地を追いながら現地で見て、結果と写真を登録する
5. 結果を自治体のGISや台帳に戻し、翌年の重点地区を決める

準備でいちばん重いのは1です。このサービスの機能一覧では「農地への位置・区画情報のひも付け作業」に印が付いていません[1]。区画データが整っていない自治体は、別に整備が要ります。農林水産省は、eMAFF農地ナビの農地ポリゴンで交付金台帳に位置情報を付ける「ひも付けツール」を案内しています[5]。

3と4の線引きは、初年度に現地の結果と突き合わせて決めます。宇部市では、開発の初期に調査員から実用性を疑う声があり、判定会で検証して理解を得たとされています[4]。前年と判定が変わった筆を優先する運用は、宇部市のシステムにある「前年との差分抽出」の機能で実現できます[4]。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| 筆ごとの判定（自動判別、要目視、要調査） | 地図（GIS）と一覧 | どの筆を画面で見るか、どの筆に現地で行くか |
| 前年との差分 | 一覧 | 判定が変わった筆の優先順位、調査員の人数と日数 |
| 現地の結果と写真 | タブレットの記録、GISへの反映 | 遊休農地とするか、利用意向調査の対象にするか |
| 調査の進捗と履歴 | システムの画面 | 進み具合の把握、監査のときの根拠 |

機能の一覧では、遊休農地と転用の判定、作物の判定、自治体やほかのGISへの結果の反映、衛星画像の上で農地を表示する画面に印が付いています[1]。紙の地図の印刷や転記がなくなり、進捗をその場で把握できるとされています[1]。

## 費用の考え方

サービス集には、参考価格として次の金額が載っています[1]。

- 初期費用：システム初期設定費用 30万円〜、圃場データ整備費用 50万円〜
- 運用費用：衛星データ購入費用 50万円〜（撮影面積により変動）、システム利用料 180万円〜

いずれも下限だけで、上限は書かれていません。基本料金に含まれないオプションは青い文字で示されていますが、どの項目がオプションかは、読み取った文字情報からは分かりません[1]。

費用がかかる所は4つです。

- **データ**：衛星データの購入費が面積で増えます。無償の衛星データだけで組んだ場合の価格は、このページには載っていません[1]。同じサービス集のRESTECのページでは、費用は「利用する衛星データ（無償・有償・高分解能などの違い）」で変わるとされています[2]
- **解析とシステム**：システム利用料が年額の中心です
- **区画データの整備**：圃場データ整備費用のほか、ひも付けが済んでいない自治体では、その作業が先に要ります
- **運用**：画面での目視と、要調査の筆の現地確認は自治体の人手で残ります

参考に、同じサービス集でRESTECは「1自治体あたり100万円程度〜500万円程度が目安（税抜）」「全県導入 1000万円程度〜」と載せています[2]。これは別の事業者の値で、この事例の費用ではありません。年額か初期費用か、何を含むかの条件がそろっていないので、横に並べて比べる前に内訳をそろえる必要があります。

## 向いている条件、向いていない条件

（ここに図：scale　衛星の自動判別に向く農地から、向かない農地まで）

| 観点 | 向いている | 向いていない |
|---|---|---|
| 農地の数 | 数万筆あり、全筆の見回りが続かない | 数千筆で、現状の見回りで回っている |
| 農地の形 | まとまった広さの田畑が多い | 狭い農地、細かい区画が多い |
| 作っているもの | 田、畑 | 果樹園、茶畑 |
| 区画データ | 農地ポリゴンがあり、台帳とつながる | 紙の台帳だけ、地番の書き方がばらばら |
| 制度 | 農地パトロールと交付金の現地確認を1つにまとめたい | 1制度だけで、対象の筆が少ない |
| 体制 | 画面での目視と線引きの見直しを続けられる | 衛星の判定だけで調査を終えたい |

## コンサルタントへの示唆

- **最初に、区画データと台帳の状態を聞く。** ひも付けの作業は、このサービスの基本の範囲に印が付いていません[1]。ここで止まると、解析の前に時間と費用がかかります
- **「98%削減」を提案の見出しにしない。** 舞鶴市の1つの結果で、年度も書かれていません[1]。初年度は自動判別の割合と、画面での目視に残る割合を、自分の自治体の数字で出すところから始めます
- **画像の分解能と費用の関係を先に説明する。** 目視に使う画像を安いものにすると、目視と現地が増えます[4]。データ購入費は面積で増えるので[1]、対象の範囲と画像の細かさを、費用と一緒に決めます
