# 地図の更新、どこが変わったかを探すのが一番重い。衛星とAIでどこまで絞れるか

（note用の下書き。見出し画像は thumbnail.png、図は fig-1.png と fig-2.png を使う。末尾のリンクを公開先のアドレスに直す）

カーナビや地図アプリ、ハザードマップの基礎になっているのが、国土地理院の電子国土基本図です。道路ができ、建物が建て替わるたびに直さなければなりません。従来は、更新に使う地図情報や空中写真と既存の地図を目視で比べて、変化を探していました。多大な労力と時間がかかり、変化の大きい場所をどう効率よく見つけるかが課題でした。

## 2時期の衛星画像をAIで比べる

国土地理院は、2023年度から2024年度にかけて、衛星画像とAIで変化を抽出する技術を開発しました。古い時期と新しい時期の衛星画像を区画ごとにAIに入力し、建物の新設と滅失、道路の新設と滅失の4種類の変化を確信度付きで出します。中分解能の画像（1.5〜2.5m）で全国4,871メッシュを選別し、その結果を地図の面的な更新の事業計画の参考資料に使いました。高分解能の画像（0.8m）では、200m²以上の建物と幅員6m以上の道路を地物の単位で抽出します。

2025年の国土地理院報告会で公表された精度は、テストデータで、建物の変化が適合率75.8%、再現率70.9%、道路の変化が適合率46.4%、再現率48.0%です。建物は4件に3件が当たり、10件に7件を拾える一方、道路は半分に届きません。

（ここに fig-1.png）

画像は、2024年1月に国産の光学衛星5機による観測サービスが採用され、2026年1月に提供が継続されたと報じられています。実証を終え、画像の継続調達とAIの採用に進んだ段階です。

## 衛星にできないこと

（ここに fig-2.png）

- 衛星とAIが出すのは「変化の候補」です。国土地理院も、図化に使うには精度の向上が必要だとしています。地図を直すのは人の工程です
- 道路の変化は建物より拾いにくく、学習データの不足で特殊な色の道路は検出できていません
- 小さな変化は対象外です。住宅1戸の建て替えや細い道は、この仕組みでは拾いません
- 衛星の入射角の違いで屋根の位置がずれ、高層の建物は側面が別の建物と誤認識される例があります
- 光学画像なので雲があれば写らず、複数回の撮影を合成して補っています

## 落とし所は「どこから更新するか」を決める材料に使う

国土地理院の使い方は、選別の結果を事業計画の参考資料にし、図化そのものは別の工程で行う、という分け方です。提案でも「地図が自動で更新される」とは言わず、変化の候補をどの順に確かめるかを決める材料と位置づけます。そして、精度は「7割」とまとめず、建物と道路で分けて示します。

画像の調達額とAIの開発費は公開されていません。本編では、更新計画に入れる手順、受け取るデータと決められること、費用がかかる4つの所、向いている対象と向いていない対象を表にまとめています。

→ 本編：衛星データとAIで地図の更新箇所を洗い出す、国土地理院の建物検出は適合率75.8%（リンクを入れる）
