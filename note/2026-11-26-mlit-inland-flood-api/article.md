# 国交省が「雨水出水（内水）浸水想定区域」のデータを不動産情報ライブラリに追加し、APIでの提供を開始。衛星データで浸水の災害データを取る自治体・建設コンサル・損害保険は、SARの浸水推定図と重ねる「照合用の地図」をどう用意するか

（note用の下書き。見出し画像は thumbnail.png、図は fig-1.png と fig-2.png を使う）

国土交通省が、2026年（令和8年）11月25日に、「不動産情報ライブラリ」に「雨水出水（内水）浸水想定区域」のデータを新たに掲載し、地図上で誰でも表示できるようにするとともに、API（プログラムから呼び出す窓口）での提供を始めたと発表しました[1]。あわせて、洪水浸水想定区域（想定最大規模）と土砂災害警戒区域のAPIのデータも更新しています[1]。不動産情報ライブラリは、不動産に関する公開データを地図上で重ねて表示し、APIで民間のシステムと連携できる国土交通省のサービスで、2024年4月に始まりました[1]。この記事では、衛星データで浸水の範囲を推定する仕事に関わる自治体の防災担当、建設コンサルタント、損害保険の査定担当の立場で、この発表から何を読み取り、何を確かめるかを整理します。

（ここに fig-1.png）

## 何が書かれているか

**内水の浸水想定区域が、地図とAPIの両方で取れるようになりました。** 「雨水出水（内水）浸水想定区域」は、下水道に雨水を排除できないこと、または下水道から河川などに雨水を排除できないことにより浸水が想定される区域と水深を示すデータです[1]。不動産情報ライブラリの地図上で、地価公示、都市計画、ハザードマップなどの他のデータと重ねて表示できるほか、APIでの提供により官民のシステムへの組み込みやデータ連携が容易になる、と書かれています[1]。

**APIの名前と出典は、操作説明に載っています。** 不動産情報ライブラリのAPI操作説明では、「国土数値情報（雨水出水（内水）浸水想定区域）API」（XKT032）として、出典は国土数値情報「雨水出水（内水）浸水想定区域（令和7年度）」と記載されています[2]。APIを使うには、利用規約に同意のうえ利用申請を行い、審査と承認を経てAPIキーの発行を受ける必要があります[2]。リクエスト数に明確な上限はないものの、連続して実行しないよう求められています[2]。

**洪水と土砂災害のデータも更新されました。** 洪水浸水想定区域（想定最大規模）と土砂災害警戒区域について、APIで提供するデータを更新したとあります[1]。操作説明では、洪水浸水想定区域（想定最大規模）は国土数値情報の令和7年度版、土砂災害警戒区域も令和7年度版が出典です[2]。

**操作性の改善は、利用者アンケートを受けたものです。** 地図画面の地域検索に住所のフリーワード検索機能が加わり、トップページに「ご利用ガイド」画面が追加されました[1]。

## 発注する側にとっての意味

**衛星の浸水推定図は、浸水想定区域と重ねて使うのが国の使い方です。** 国土交通省が11月10日にとりまとめた都市型水害への対策方針の参考資料では、千葉市と大網白里市について、衛星画像から浸水範囲を推定し、浸水想定区域図（想定最大規模）と重ね合わせた結果、浸水したと想定される範囲はおおむね浸水想定区域内であることが確認できた、としています[3]。この重ね合わせに使う「照合用の地図」の一つが、今回APIで取れるようになった内水の想定区域です。これまで市町村ごとに図やデータを集めていた作業が、全国で同じ形式のデータを一つの窓口から取る作業に変わります。

**自治体は、自分の区域の内水の想定区域が「載っているか」を確かめる場面です。** 対策方針のとりまとめでは、下水道区域外では内水の浸水想定区域図が作成されていない場合が多いことが課題に挙げられています[4]。下水道の整備地域は全面積の約6%、可住地面積の約17%です[4]。大網白里市の浸水では、浸水した川の周辺が下水道区域でなかったため、洪水浸水想定区域と内水浸水想定区域のいずれも作成対象になっていませんでした[3]。APIで取れるのは作成・公表済みのデータなので、自分の区域が空白かどうかは、取ってみて初めて分かります。

**建設コンサルタントには、納品物の「重ね合わせの元データ」を明示する材料です。** 衛星で推定した浸水範囲を納める業務では、どの浸水想定区域と重ねたか（内水か洪水か、想定最大規模か計画規模か、何年度版か）で結論が変わります。出典と年度が操作説明に書かれているデータ[2]を使えば、納品物にその出典を書き添えられます。

**損害保険の査定では、「想定の外」で起きた浸水を見つける手がかりになります。** 衛星の推定図だけで判断するのではなく、事前の想定区域と重ねて、想定の外で起きた浸水を見つけるのが、国の資料の使い方です[3]。内水の想定区域がAPIで取れれば、洪水の想定区域だけでなく内水の想定とも重ねられます。

## 変わらないこと

- **空白域は、データが公開されても埋まりません。** 下水道区域外の内水や、市町村が管理する準用河川・普通河川の洪水については、想定区域図が作成されていない場合があります[4]。国は、来年の出水期までに地形分類図などを用いた「浸水ポテンシャル地形（仮称）」の技術的な検討を行って公表し、5年以内に空白域のリスク情報を高度化する新たな手法の開発を目指すとしています[4]
- **衛星の推定図は、実際の浸水範囲と異なる可能性があります。** 国の参考資料の図にも、発災直後のSAR衛星画像を用いた推定図であり、実際の浸水範囲と異なる可能性がある、と注記されています[3]。重ねる相手の想定区域が正確でも、推定図の側の誤りは残ります
- **APIは申請と承認が必要で、使い方にも制約があります。** 利用申請と審査を経てAPIキーが発行され、連続したリクエストは避けるよう求められています[2]。災害の直後に初めて申請するのでは間に合いません
- **データの年度は、国土数値情報の令和7年度版です。** 自治体が最近公表した想定区域図が、まだ反映されていない可能性があります[2]

## 今、できること

1. **自治体の防災担当**：不動産情報ライブラリの地図で、自分の区域の内水浸水想定区域が表示されるかを確かめる[1]。表示されない場所があれば、それが「作成対象外」なのか「未反映」なのかを、下水道部局と確かめる
2. **建設コンサルタント**：浸水範囲の推定を納める業務で重ねる想定区域の種類と年度を、仕様書か納品物に書く欄を用意する。APIを使う場合は、平時に利用申請を済ませ、取得したデータの出典と年度を記録しておく[2]
3. **損害保険の査定担当**：衛星の推定図と重ねる想定区域に、洪水だけでなく内水の想定区域を加える。想定の外で浸水が推定された場所は、現地確認の優先順位を上げる材料にする
