# 沖合の漁場探しを、衛星の水温図で短くする：出漁前と操業中に、向かう海域を船の上で決める

（noteに貼る全文。全部を公開する。図は、サイトの記事の図を使う）

## この記事で分かること

- 沖合の漁船が、衛星から作った海の情報を、どの場面で使っているか
- 公表されている効果の数字と、その数字の性質（利用者アンケート）
- 雲、通信、沿岸、海の中という4つの限界

## どんな使い方か

魚は、種類ごとに好む水温や海の色の範囲があります。沖合の漁船は、その条件に合う海域を探して走ります[1]。水温図がなければ、漁場探しに時間と燃料がかかります[3]。

衛星は、広い海の表面の水温を一度に測れます。ただ、沖合の船は通信が細く、陸上と同じようには情報を受け取れません[2]。

そこで、衛星のデータを陸上で解析し、沖合でも受け取れる軽さに加工して、船に届けるサービスが使われています。船の上では、水温の分布や予測された漁場の図を見て、向かう海域を決めます[2]。

## 事例：漁業情報サービスセンター「エビスくん」

一般社団法人漁業情報サービスセンター（JAFIC）が、2008年に始めた情報サービスです[1]。実証ではなく、有料のサービスとして運用されています[1][4]。

- 海面の水温、風、波の高さなどを、1つの画面で見られます。直近の状況に加えて、予測の海の状況と、予測の漁場の図も届けます[2]
- もとになるのは、複数の衛星の観測と、協力する漁船が測った値です。同センターが独自に解析します[2]
- 使う衛星として、日本の「しきさい」「しずく」「ひまわり」が挙がっています（2022年の資料）[2]
- 夜の光を写した画像も見られます。外国の漁船が操業している位置の確認に役立つとされています[1]

同センターは2018年に、利用している漁船452隻にアンケートを行い、150隻から回答を得ました[1]。

（ここに図：effect　利用者アンケートで答えられた効果の幅）

- 漁場を探す時間：15〜33%短縮
- 漁獲量：10〜25%増加
- 給油：4〜23%削減

これは利用者が答えた値で、計器で測った値ではありません。漁業の種類ごとの内訳は示されていません[1]。

## 2026年時点の限界

（ここに図：limits　この使い方の4つの限界）

**技術的な限界**

- **雲があると、見えないセンサーがある。** 光や赤外線で測る衛星は、雲があると海が見えません。電波（マイクロ波）で測る「しずく」は、少しの雲なら海を見られます[3]。ただし、マイクロ波の水温図は、赤外線のものより目が粗くなります【要確認】
- **沖合では、通信が最大の制約。** 衛星のデータは大きくなる一方です。洋上で自由に受け取ることが「最大のネック」とされています[1]
- **沿岸の赤潮には、要求が厳しい。** 赤潮のような沿岸の現象では、衛星データに求められる条件が厳しいとされています[1]。沖合向けの水温図を、そのまま沿岸の養殖に使えるとは限りません

**衛星では分からないこと**

- **海の中は見えない。** 衛星が測るのは海の表面です。海の中の様子は、計算で海を再現する数値モデルで補います。同センターは、衛星とモデルを「両輪」と位置づけています[1]
- **魚そのものは見ていない。** 予測の漁場の図は、過去の漁場の記録と海のデータを機械学習にかけて作ります[1]。見ているのは魚の好む条件で、魚群ではありません
- **船が測る値が減っている。** 漁船と調査船が減り、現場で測るデータが集まりにくくなっています。情報の精度に影響が出ているとされています[1]

## （仮）自社の業務に入れるなら

沖合で操業する漁業会社の、漁場選びに入れる場合を想定した例です。

（ここに図：flow　出漁前と操業中に、水温図を見る手順）

1. 狙う魚の種類と、好む水温の範囲を整理する
2. 出漁の前に、水温図、風と波の予測、予測の漁場の図を見る
3. 向かう海域と、出漁するかどうかを決める
4. 操業中に、船の上で更新された図を見て、移動するかを決める
5. 漁獲と水温を記録し、予測が当たったかを振り返る

準備として要るのは、船の通信の手段と、図を表示する端末です。どの海域まで、どの回線が届くかを先に確かめます。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| 日々の海面の水温図 | 船上の画面の図 | 向かう海域。水温の境目のどちら側を探すか |
| 風と波の予測 | 地点ごとの予測 | 出漁するか、いつ戻るか |
| 予測の漁場の図 | 図 | 探す海域の順番 |
| 夜の光の画像 | 画像 | ほかの船が集まっている海域の把握 |
| 自船の漁獲と水温の記録 | 自社の記録 | 予測をどこまで信じるか。契約を続けるか |

## 費用の考え方

利用料の金額は公開されていません。水産庁の事業者一覧は、このサービスの料金を「月額契約（内容により変化）」としています[4]。

費用がかかる所は、次の3つです。

- **情報サービスの利用料**：月額。見る情報の内容で変わる[4]
- **船の通信費**：沖合で受け取るための回線。データが大きいほど負担が増える[1]
- **端末と慣れ**：図を読んで判断に使うまでの時間

もとの衛星は、国の機関が運用しています【要確認】。利用者が衛星データを直接買う形ではありません。費用の中心は、解析と配信のサービスの側にあります【要確認】。

元が取れるかは、燃料費で考えます。利用料と通信費の合計を、年間の燃料費に削減率を掛けた額と比べます。アンケートの削減の幅は4〜23%と開きがあります[1]。小さい側の数字で成り立つかを見ます。

## 向いている条件、向いていない条件

| 観点 | 向いている | 向いていない |
|---|---|---|
| 漁場 | 沖合。広い海域から探す | 沿岸の決まった漁場、養殖場 |
| 狙う魚 | 水温の境目に集まる魚 | 海底近くにいる魚（表面の水温と結びつきにくい）【要確認】 |
| 天候 | 晴れ間のある海域と時期 | 雲が続く海域と時期 |
| 通信 | 沖合で使える回線がある | 回線が細く、図を受け取れない |
| 知りたいこと | 海域の当たりを付ける | 魚群の正確な位置、赤潮の発生 |

## コンサルタントへの示唆

- **最初に、船の通信環境を聞く。** 情報の質より前に、沖合で受け取れるかが制約になります
- **効果の数字を、測定値として引かない。** 公表されているのは利用者アンケートの幅です。提案では、小さい側の数字で試算します
- **沖合の成功を、沿岸に持ち込まない。** 赤潮や養殖の監視は、求められる細かさと頻度が違います。別の使い方として設計します
