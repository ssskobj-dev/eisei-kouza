# 同じ田んぼの中で、育ちがそろわない。衛星データの地図で肥料の量を変えると、農業の現場で収量はどこまで変わるか

（note用の下書き。見出し画像は thumbnail.png、図は fig-1.png と fig-2.png を使う。末尾のリンクを公開先のアドレスに直す）

1枚の水田の中でも、土の力は場所によって違います。同じ量の肥料をまくと、育ちすぎる場所と足りない場所ができ、収量と品質がそろいません。場所ごとに肥料の量を変える「可変施肥」は、このムラをならす方法です。問題は、どこに多く、どこに少なくまくかを、どうやって決めるかです。

## 衛星画像から作った地図を、田植機に送る

BASFの営農支援システム「ザルビオ フィールドマネージャー」は、衛星画像とAIの解析で、圃場の生育の状況と推定した地力をもとに、可変施肥マップを作ります。JA全農、クボタ、BASFは2024年3月19日、この地図をクボタの営農支援システム「KSAS」に自動で移し、対応する田植機が地図どおりに施肥する連携を始めました。それまでは、USBメモリーなどでデータを運んでいました。

（ここに fig-1.png）

提供の前の2023年に、2つの法人で実証が行われています。地力窒素（土の中で分解され、作物が使える窒素）の量が同じ程度の圃場で比べると、可変施肥は慣行の施肥より4〜5%の増収でした。

## うまくいかない条件

（ここに fig-2.png）

公的な試験の報告には、うまくいかなかった例も書かれています。

- 長野県農業試験場の令和5年度の試験では、収量は可変施肥区が563kg、均一に施肥した区が561kg（10aあたり）で、差はありませんでした。もともとの収量が高く、増収の余地が少なかったと考察しています
- 梅雨の時期など晴れた日が少ないと、衛星は撮影できません
- 地力マップは土を測ったものではなく、過去10〜15年分の衛星画像の生育の傾向から区分けしたものです
- 水の管理、雑草、苗の量が原因のムラは、肥料の量を変えても直りません
- 対応する田植機が要ります。方式は農機のメーカーごとに違います

## 落とし所：比べる圃場を決めてから始める

可変施肥が効きやすいのは、地力のムラが大きく、力の弱い場所がある圃場です。もともと収量が高くそろっている圃場では、差が出にくくなります。

始めるときは、均一に施肥する圃場を残し、収量を場所ごとに測って比べます。比べる相手を決めずに始めると、効果があったかどうかが分かりません。田植機は、可変施肥のためだけに買い替えるのではなく、更新の時期に合わせて対応する機種を選ぶ、という順番が現実的です。

本編では、公表されている利用料と田植機の価格、基肥の設計に入れる5つの手順、受け取るデータと決められること、向いている条件と向いていない条件を表にまとめています。

→ 本編：水稲の可変施肥を、衛星データの施肥マップと田植機の連携で行う：実証は4〜5%の増収、県の試験は差なし（リンクを入れる）
