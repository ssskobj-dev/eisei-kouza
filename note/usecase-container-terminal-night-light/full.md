# 夜の衛星データでコンテナターミナルの稼働を見分ける：東京港の8ターミナルを5.1mの夜間画像1枚で判定し、消灯していた1か所を識別した東京大学の研究に見る、港湾の物流データの作り方と限界：荷主や物流の研究者が、船の位置情報（AIS）では分からない「夜に荷役しているか」を、照明の明るさから推定する研究。画像は1枚、港は1つ、明かりが点いていても荷役中とは限らない、という限界も論文に書かれている

## この記事で分かること

- 荷主や物流の研究者が、船の位置情報だけでは分からない「ターミナルが夜に動いているか」を、夜の衛星データで推定しようとする考え方
- 東京港の8ターミナルを、分解能5.1mの夜間画像1枚で判定した研究の方法と数字[1]
- 画像1枚・港1つの検証、照明と荷役は別、無償の夜間光では粗すぎる、といった限界と、費用の考え方

## どんな使い方か

コンテナ船の遅れは、港のターミナルの混み具合に左右されます。混んでいると分かれば、荷主や船社は近くの別のターミナルや港に荷物を振り向けられます。しかし、世界中のターミナルの運営者に稼働状況を定期的に聞いて回ることは現実的ではありません。船の位置を知らせる自動識別装置（AIS）のデータも、船が港にいることは分かっても、ターミナルの中で夜にコンテナを扱っているかまでは分かりません[1]。

そこで東京大学の研究グループは、夜の地上の光を高い分解能で捉える衛星の画像から、ターミナルの照明が点いているかを読み取り、夜間の稼働を判定することを試みました[1]。衛星の役割は、照明の明るさから「稼働している可能性が高いターミナル」を面で示すことです。実際に荷役が行われているかの確認、輸送網のモデルへの反映、寄港先の判断は、人の仕事として残ります。

## 事例：東京港の8ターミナルを夜間画像1枚で判定（東京大学、2023年）

東京大学の村田氏らは、2023年7月に学術誌で、東京港のコンテナターミナル8か所の夜間の稼働を、夜間画像から判定した研究を発表しました[1]。研究の位置づけは実証で、業務としての運用ではありません。

- 使った画像は、キヤノン電子の超小型衛星CE-SAT-IIBが2021年4月6日21時03分（日本時間）に撮った夜間の画像1枚です。CE-SAT-IIBは重さ35.5kgの超小型衛星で、口径200mmの望遠鏡と超高感度カメラを載せ、赤・緑・青の3つの色の帯を持ち、画素の大きさは5.1mです[1][2][3]。比較のため、翌日の昼に欧州のSentinel-2Aが撮った画像（画素10m）も使っています[1]
- 東京港は2021年に486万TEU（20フィートコンテナ換算）を扱う国内最大のコンテナ港で、トレーラーの待ち時間が30分から2時間47分に及ぶ混雑が課題になっています[1]
- 正解のデータは、AIS（Lloyd's List Intelligenceのデータ）と、ターミナル運営者への聞き取りで作りました。撮影時に船が着いていたT3、T6、T8は「点灯」、運営者が消灯を確認したT1は「消灯」としています[1]
- 8ターミナルの画素ごとの明るさ（デジタル値、14ビット）を色の帯ごとに箱ひげ図にしたところ、緑と赤の帯では、消灯していたT1と他の7か所の値の範囲が重なりませんでした。青の帯は重なりました[1]
- 消灯していたT1の値の80パーセンタイル（緑3,947、赤7,167）をしきい値にし、画素の90%以上がしきい値を超えていれば「稼働」とする判定で、残りのT2、T4、T5、T7はすべて稼働と判定されました[1]

論文は、青の帯の値が高かったT7とT8を船から撮影して確かめ、白色LEDの照明と、黄色味のある高圧ナトリウム灯の色の違いが画像に表れていることも報告しています[1]。研究費は、リモート・センシング技術センター（RESTEC）の2022年の研究助成です[1]。

## 2026年時点の限界

（ここに図：limits　この使い方の5つの限界）

**画像1枚、港1つの検証で、しきい値は他の画像に移せない。** 論文は、分析した画像が1枚だけであること、時系列や他の港での研究が今後の課題であることを明記しています[1]。しきい値は画像のデジタル値で決めており、昼の光学衛星のように物理的な明るさ（放射輝度）に変換する式がないため、別のセンサーや別の日の画像で同じ値を使えるかは分かりません[1]。

**照明が点いていても、荷役をしているとは限らない。** T7は点灯と判定されましたが、次の船が着いたのは翌日の夕方でした。論文は、船がいなくても夜に何らかの作業をしていたか、隣のT8の光が映り込んだ可能性を挙げています[1]。逆にT4は、撮影の1時間30分後に着く船の準備で点灯していたと推定されています[1]。判定は「照明の点灯」で、「荷役の有無」ではありません。

**無償の夜間光では、ターミナルを分けられない。** 論文が挙げる夜間光の衛星は、米国のDMSP/OLSが分解能3,000m、VIIRSが740m、中国の珞珈一号が130mです[1]。東京港のターミナルを個別に判定できたのは5.1mの画像だからで、論文は130mでも難しいだろうとしています[1]。一方で、CE-SAT-IIBでも街灯1本ずつは取り出せず、それができるのは中国のJL1-3B（0.92m）です[1]。

（ここに図：resolution　夜間光を観測する衛星の画素の大きさ）

**1枚の範囲は3.5km×2.3kmで、定期観測の仕組みはない。** CE-SAT-IIBの観測範囲は3.5km×2.3km、再訪は約5日です[2]。論文は、夜間光を観測できる衛星は少なく、コンステレーション（多数機の群）はまだないとしています[1]。今回の画像も、通常は品質を保証できないとして切り落とす端の部分を、特別に含めて提供されたものです[1]。

**雲があると撮れない。** 可視光で夜の照明を見る方法なので、雲に覆われた夜は使えません【要確認】。論文に雲の記述はなく、一般的な知識から書いています。

## （仮）自社の業務に入れるなら

荷主の物流部門や、海運の輸送網を分析する調査会社が、稼働情報を公表しない港の夜間稼働を推定する場合を想定した例です。

（ここに図：flow　夜間画像でターミナルの稼働を推定する手順）

1. 対象の港を選び、ターミナルの区画を地図上に描く[1]
2. 夜間の高分解能画像を、対象の港と日時を指定して発注する[1][2]
3. 区画ごとに、画素の明るさの分布（箱ひげ図）を出す[1]
4. 緑と赤の帯にしきい値を置き、点灯と消灯を分ける[1]
5. AISや運営者の情報と突き合わせ、輸送網のモデルの処理能力や、寄港先の候補に反映する

準備として要るのは、1のターミナルの区画と、5で突き合わせるAISのデータです。論文は、ターミナル運営者の情報とAISを組み合わせることで、世界のターミナルの夜間の稼働の傾向をつかめるようになるとしています[1]。

コンサルタントや解析の受託者にとっては、2の画像の調達、3と4のしきい値の設計、5の輸送網モデルへの反映が仕事になります。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| ターミナルごとの点灯・消灯の判定 | 一覧表、地図 | 夜間に稼働している可能性のあるターミナル。追加で確かめる対象 |
| 区画ごとの画素の明るさの分布 | グラフ、数値 | しきい値をどこに置くか。判定をどこまで信じるか |
| 点灯の判定とAISの突き合わせ結果 | 一覧表 | 輸送網モデルで、そのターミナルの夜間の処理能力をどう置くか |
| 照明の色の違い（白色LEDか否か） | 画像、数値 | 照明の更新状況の把握。判定のしきい値を港ごとに変える必要の有無 |

判定は「照明が点いているか」までです。荷役の有無や処理量は、AISや運営者の情報と合わせて初めて推定できます[1]。

## 費用の考え方

この研究の費用は公開されていません。研究費はRESTECの2022年の研究助成です[1]。

費用がかかるのは、次の3つです。

- **夜間画像の調達**：CE-SAT-IIBの画像は商用データで、販売代理店から購入します[1]。RESTECが2022年7月5日に販売を始めました[1]。金額は公開されていません。港ごと、撮影ごとに費用がかかります
- **区画の作成としきい値の設計**：ターミナルの区画を描き、画像ごとに明るさの分布を出す人件費です。しきい値を他の画像に移せない現状では、画像ごとに検証が要ります[1]
- **突き合わせの情報**：AISのデータは有償のサービスが多く、論文も商用のデータを使っています[1]。運営者への聞き取りは人の時間です

無償の夜間光（VIIRSなど）では分解能が足りず、ターミナル単位の判定は成り立ちません[1]。無償で成り立つ構成ではなく、有償の夜間画像が前提です。

## 向いている条件、向いていない条件

（ここに図：scale　効きやすい条件から、効きにくい条件まで）

| 観点 | 向いている | 向いていない |
|---|---|---|
| 知りたいこと | 夜に照明が点いているターミナルの当たり | 荷役の有無、処理量そのもの |
| 対象の数 | 稼働情報を出さない特定の港を数か所 | 世界中の港を毎晩 |
| 画像 | 5m級の夜間の高分解能画像を調達できる | 無償の夜間光（数百m）だけで済ませたい |
| 突き合わせ | AISや運営者の情報と組み合わせられる | 衛星の判定だけで決めたい |
| 天候 | 晴れた夜を選べる | 雲の多い時期に毎回必要 |

## コンサルタントへの示唆

- **最初に、AISで足りない部分を聞く。** 船が着いているかはAISで分かります。衛星が足すのは「ターミナルの中の夜の照明」だけです[1]。顧客の困りごとがAISで済むなら、夜間画像は要りません
- **「夜間の荷役が分かる」と言わない。** 論文で言えるのは、照明の点灯と消灯の判定までです。点灯していても船のいないターミナルがありました[1]
- **画像1枚ごとの検証費用を見積もりに入れる。** しきい値は画像のデジタル値で決めており、別の画像に移せる保証がありません[1]。港や撮影ごとに正解データとの突き合わせが要ります
