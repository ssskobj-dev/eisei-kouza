# 台風の強度を、気象衛星ひまわりの雲の形から推定する：2020年台風10号は速報920hPa、確定910hPa：防災の判断に使う衛星データの解析値。ドボラック法で決められることと、10hPa単位の幅が残るという限界

（noteに貼る全文。全部を公開する。図は、サイトの記事の図を使う）

## この記事で分かること

- 台風情報に出る中心気圧と最大風速は、海の上で直接測った値ではなく、気象衛星ひまわりの画像の雲の形から推定した値であること。2020年の台風第10号は、速報値が920hPa、のちの確定値が910hPaでした[1][2]
- 同じ判定でも、航空機で測った中心気圧は10hPa程度以上ばらつくことなど、2026年時点の限界[4]
- 企業や自治体が、操業の停止や体制の判断に使うときの工程と、お金がかかる所

## どんな使い方か

台風の強さは、中心気圧と最大風速で表します。ところが、台風の多くは海の上にあり、中心の近くに観測点はありません。北西太平洋では、米軍が1987年に航空機の観測をやめてから、台風の中心付近を直接測る機会がほとんどなくなりました[5]。

そこで使われているのが、静止気象衛星の画像から強度を推定する方法です。ドボラック法と呼ばれます。画像に写る台風の雲の形（雲パターン）と強度を統計的に結び付け、発達の程度を表す数（CI数）を決めます。CI数と最大風速の統計的な関係から、強度を推定します[1]。気象庁は、赤外画像の特定の温度帯を色で強調した画像を使って、この解析を行っています[1]。

もとになる気象衛星ひまわり8号・9号は、16の波長帯で観測しています。地球全体を10分ごと、日本域を2.5分ごとに撮り、台風の追跡などのために1,000km四方の領域を2.5分ごとに撮る観測もあります[7]。

台風情報を受け取る側から見ると、この解析値は、操業の停止、船の避航、事故の受付体制などを決める出発点になります。

## 事例：気象庁による2020年台風第10号の解析（本格運用）

気象庁の予報課の担当者が、日本気象学会の機関誌「天気」で、2020年の台風第10号の解析を紹介しています[1]。

- 台風第10号は、2020年9月5日から7日にかけて、大型で非常に強い勢力で日本に近づきました。南西諸島や九州を中心に、暴風や大雨をもたらしました[1]
- 最盛期の強さは、中心気圧920hPa、最大風速100ノット（1ノットは約0.51m/s）と解析されました。記事は、これが速報値であると断っています[1]
- この台風は、発達のとき、ドボラック法の典型に比較的近い雲パターンを示していました[1]
- 気象庁は、ドボラック法の結果を重視して台風の強度を推定します。ただし、最終的な決定には地上の観測データなども使います[1]

これは実証ではなく、気象庁が台風のたびに行っている本格運用の業務です。ドボラック法は、世界気象機関の地域センターや各国の気象機関で、熱帯低気圧の強度を推定する標準の方法とされています[9]。

のちに気象庁が公表した台風位置表では、この台風の最低の中心気圧は910hPa、最大風速は55m/sで、9月4日21時（日本時間）に記録されています[2]。台風位置表は、確定値として公表される資料の1つです[3]。速報値は、限られた時間に集めたデータで解析した値です。確定値は、台風が消えた後に、後から集まった資料も使って位置と強度を解析し直した値です[3]。この台風では、最盛期の中心気圧が、速報値と確定値で10hPa違いました[1][2]。

## 2026年時点の限界

（ここに図：limits　この使い方の5つの限界）

**技術的な限界**

- **同じ判定でも、実際の気圧は10hPa程度以上ばらつく**。気象庁の研究者は、1981〜1985年の米軍の航空機観測500個を、CI数と比べ直しました。現行の換算表は平均としては妥当でした。しかし、同じCI数でも航空機で測った中心気圧の標準偏差は10hPa程度以上あり、換算表の値と20hPa以上違う観測も少なくありませんでした[4]
- **近年も、直接の観測と10〜15hPaずれた例がある**。2017年の台風第21号では、名古屋大学などが航空機で中心付近を観測しました。気象庁の確定値935hPaに対して観測は925hPa、別の時刻は確定値915hPaに対して観測は約930hPaでした[5]
- **速報値は後で変わる**。上の事例のとおり、最盛期の中心気圧は速報値と確定値で10hPa違いました[1][2]
- **典型から外れた台風では、誤差が大きくなりやすい**。眼が小さい台風、周りの気圧が低い弱い台風、陸地に近づいた台風が挙げられています。判定には急な変化を抑える決まり（6時間で±1.0までなど）があり、短い時間の強度の変動は捉えられないとされています[4]
- **解析者の判断が入る**。雲の型の判定は人が行い、主観によるばらつきは完全には除けないとされています[4]
- **長い期間の統計は、完全にはそろわない**。気象庁は1987〜2016年の30年分を同じ方法で解析し直しましたが、衛星の世代の違いなどがあり、完全な一貫性は得られないとしています[9]

**衛星では分からないこと**

- **測っているのは雲で、海面の気圧や風ではない**。画像から雲の形を読み、統計的な関係で強度に直す間接の推定です[1]。直接の観測ではないため、航空機の観測より不確実性が高いと考えられています[5]
- **自社の拠点での風や雨は出ない**。中心気圧と最大風速は台風全体を代表する値で、ある地点の風速や雨量ではありません【要確認】
- **この先の強さは、別の方法（予報）で出す**。強度の予報には統計的な手法などが使われ、急に発達する台風の予測は難しいとされています[8]。台風第10号では、9月5日18時の予報は九州南部に近づく時点で920hPaを見込み、6日6時の予報で935hPaに変わりました[6]

## （仮）自社の業務に入れるなら

製造業の工場の操業、海運の運航、損害保険会社の事故の受付体制を想定した例です。実在のサービスではなく、想定の手順です。

（ここに図：flow　台風の解析値を、接近前後の判断に入れる手順）

1. 平時に、判断の基準を決める。中心気圧の1つの値ではなく、「解析値が10hPaずれても結論が変わらないか」を確かめた基準にする[4][5]
2. 接近の数日前から、気象庁の台風情報の解析値と予報を、自社の拠点や航路の地図に取り込む
3. 予報が更新されるたびに、判断を見直す。台風第10号では、12時間で接近時の見込みが920hPaから935hPaに変わりました[6]。操業の停止や増員は、段階を分けて決めておく
4. 通過後は、速報値をもとに被害の見込みを出す。速報値であることを、社内の報告に書く
5. 確定値が公表されたら、記録と、損害の見積もりに使う式の入力を直す[3]

準備として要るのは、拠点や契約の位置を入れた地図と、判断の基準の表です。

注意が1つあります。気象庁の許可を受けて予報を行う事業者でも、台風かどうかの区別と台風の名前は気象庁の予報に従う条件が付いています。不特定多数に向けて伝えるときは、気象庁の情報の解説にとどめることが基本です[8]。自社で衛星画像から強度を解析して外に出す、という使い方は、この記事の想定に入れていません。

コンサルタントの仕事は、1の基準づくりと、5の記録の直し方の設計です。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| 台風情報の解析値（中心気圧、最大風速。速報値） | 気象庁の発表 | 接近前の体制、操業の停止の段階、船の避航の検討 |
| 台風の予報（進路と強度） | 同上 | いつまでに決めるか。更新ごとの見直し |
| 確定値（台風経路図、台風位置表、ベストトラックデータ）[3] | 気象庁の「過去の台風資料」 | 事後の記録、損害の見積もりの入力の更新 |
| ひまわりの画像[7] | 気象庁のホームページで閲覧。もとのデータは気象業務支援センターから | 台風の位置と雲の広がりの確認、社内への説明 |
| 自社の被害の記録 | 自社で記録 | 次の台風で使う基準の見直し |

速報値で動き、確定値で直す。この2段を、最初から業務の流れに入れておきます。

## 費用の考え方

- **データ**：ひまわりの画像は、気象庁のホームページで見られます[7]。確定値は、気象庁の「過去の台風資料」に掲載されています[3]。情報量の多いもとのデータ（ひまわり標準データなど）は、気象業務支援センターから入手します[7]。センターは、利用者に負担金の支払いを求めることができる仕組みです[10]。金額は、確かめた資料には書かれていません
- **解析**：強度の解析は気象庁が行います。利用者が衛星画像を解析する費用はかかりません
- **システム**：台風情報を自社の地図や基準の表に取り込む仕組みと、担当者の時間に費用がかかります。金額は公開されていません
- **運用**：予報の更新ごとの見直しと、確定値での記録の修正に、担当者の時間がかかります

仮定：気象庁が公表する解析値と予報を読んで判断するだけなら、衛星データを買う費用はゼロです。費用は、自社の地図への取り込みと、判断の基準を作る作業に限られます。ひまわりのもとのデータを自社で受け取って処理する場合は、センターへの負担金と処理の仕組みが別に要ります。

## 向いている条件、向いていない条件

（ここに図：scale　効きやすい条件から、効きにくい条件まで）

| 観点 | 向いている | 向いていない |
|---|---|---|
| 知りたいこと | 台風の強さのおおよその段階と、その変化 | 拠点ごとの風速、雨量 |
| 判断の基準 | 10hPaずれても結論が変わらない基準 | 5hPaや10hPaの差で分かれる基準 |
| 台風の型 | 眼がはっきりした、典型に近い台風 | 眼が小さい、陸地に近い、急に変わる台風 |
| 時間 | 接近前の体制、通過後の記録 | 数時間単位の細かい強度の変化 |
| 記録の扱い | 確定値で直す手順がある | 速報値をそのまま確定の記録にする |

## コンサルタントへの示唆

- **最初に、顧客の基準が「1つの値」で切られていないかを聞く**。920hPaと910hPaの違いで判断が変わる基準は、速報値と確定値の差だけで結論が変わります[1][2]
- **「衛星で台風の気圧を測っている」と言わない**。雲の形からの推定で、直接の観測と10〜15hPaずれた例があります[5]。提案では「推定値」「速報値」と書きます
- **確定値で直す工程を、提案に入れる**。保険の損害の見積もりや、被害の記録に使うなら、後から値が変わる前提で流れを作ります[3]
