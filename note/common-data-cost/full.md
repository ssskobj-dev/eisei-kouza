# データの入手方法と費用の考え方：無償か商用か、過去の蓄積か新しく撮るか

（note用の全文。「ここから有料」の行より下が有料の範囲。図は、サイトの記事の図を使う）

## この章で分かること

- 無償で使える衛星データと、お金を払って買う衛星データの違いを説明できる
- すでに撮られたデータ（アーカイブ）を買うことと、新しく撮ってもらうことの違いを説明できる
- 衛星データの費用を、データ代、解析、確認の3つに分けて考えられる
- 買う前に確かめる「利用条件」が何かを言える

## まず結論

衛星データの入手は、「無償か商用か」と「過去の蓄積か新しく撮るか」の2つの軸で整理できます。費用はデータ代だけではなく、解析する費用と、結果を現地で確かめる費用を足して考えます。そして、価格と同じくらい大切なのが利用条件です。誰が、何に、どこまで使えるかを、買う前に確かめます。

（ここに図：free-vs-commercial　この章の結論：無償データと商用データ）

## 無償データ：公共の図書館のように使う

衛星データの中には、誰でも無償で使えるものがあります。公共の図書館にたとえると分かりやすいです。蔵書は誰でも読めますが、自分の読みたい本を新しく買ってもらうことはできません。

代表は、欧州連合（EU）のコペルニクス計画の衛星、Sentinel-1や光学のSentinel-2です。利用条件は「無償、全面的、開放的」なアクセスと定められています[1]。複製、配布、公衆への伝達、改変、他のデータとの組み合わせが認められています[1]。条件は、配布するときに「Copernicus Sentinel data [年]」などの出所を書くことです[1]。

米国のLandsatも同じです。米国地質調査所（USGS）は、配布するデータに利用や再配布の制限はないとしています[3]。Landsatは2008年に無償化され、1日あたりの取得数は53シーンから5,775シーンに増えました[4]。

日本の衛星にも無償のデータがあります。JAXAは「だいち」シリーズのうち、だいち2号（ALOS-2）の広域観測モード（ScanSAR）の観測プロダクトを公開しています[5]。対象は2014年8月から2025年7月までの過去データで、新しい観測分も順次公開される予定です[6]。利用条件に同意すれば誰でも無償で使えますが、「提供：JAXA」のような出所の表示が要ります[6]。災害関連のデータは、政府や自治体の公共利用、研究などの非商用に限られ、商用利用は問い合わせが必要です[6]。

経済産業省の事業で整備された衛星データプラットフォーム「Tellus」にも、無償のデータが並んでいます[7][9]。ただし、無償でも使える場所に条件が付くものがあります。たとえばだいち2号（ALOS-2）の高分解能のデータは、Tellusの環境の中でだけ使えるもので、商用利用には別の取り決めが要ります[8]。

無償データの共通点は、世界中を決まった計画で撮り続けていることです。Sentinel-1は、あらかじめ決めた計画で観測し、長期の一貫した記録を作ることを目的にしています[2]。だから過去の蓄積が厚く、「いつから変化したか」を調べる用途に向きます。反面、撮る場所や時期を利用者が頼むことはできません。

## 商用データ：細かく撮れるが、条件は契約で決まる

商用データは、民間の衛星会社や配布事業者から買うデータです。書店で本を買うのに近く、欲しいものを選べますが、お金と条件が付きます。

商用データの強みは細かさです。衛星が撮る画像の細かさを「分解能」といいます。無償のSentinel-1の標準的なモードは5m×20mですが[2]、商用のSAR衛星には1m未満のモードがあり、防衛省の研究所の仕様書は0.5m級と0.9m級の画像を指定しています[15]。日本のだいち2号（ALOS-2）の細かいモードも有償です。環境省のマニュアルは、2017年3月時点の価格として、観測モードや時期によらず1シーン8万円（税抜）と書いています[10]。価格は変わるので、現在の価格は配布事業者に確かめます。

2024年に打ち上げられただいち4号（ALOS-4）は、JAXAが選んだ複数の民間事業者がデータを配布する仕組みです[11]。一般の利用者は事業者を通じて買います[11]。JAXAの募集時の質問と回答によると、だいち2号（ALOS-2）で無償だった広域観測モードも、だいち4号（ALOS-4）では有償です[12]。

商用データの価格は、1シーン（1枚）ごとに課金する形が多く、2011年の調査では面積に応じた課金が求められていました[14]。面積で買う形もあります。高知県の仕様書は、対象区域2,966km²の写真地図とその利用権利を1式で買う形です[17]。「何を単位に、いくらか」を見積もりで確かめます。

見落としやすいのが「検索は無料でも、注文には手続きが要る」ことです。JAXAのだいち2号（ALOS-2）の検索システムは検索だけなら無料で、注文には協定によるIDが要ります[10]。

## アーカイブと新規撮像：すでにある写真か、これから撮る写真か

同じ商用データでも、「アーカイブ」と「新規撮像」では意味が違います。

（ここに図：flow　入手までの5つの手順）

**アーカイブ**は、すでに撮られて蓄積されたデータです。過去の状態を調べる用途は、アーカイブでしか成り立ちません。ただし、知りたい場所と時期のデータが必ずあるとは限りません。環境省のマニュアルは、衛星データが調査範囲を常に網羅しているとは限らないので、実際に蓄積されたデータを確かめてから購入する、と注意しています[10]。

アーカイブの厚さは、衛星の観測計画で決まります。だいち2号（ALOS-2）は、日本全域を決まったモードで年に数回撮る「基本観測シナリオ」を持っています[13]。細かい3mのモードは、日本域を抜けなく撮るのに最短56日かかり、年に最大4回の計画です[13]。つまり、ある場所を見られる日は年に数日しかありません。しかも「必ず撮る」のではなく、ほかの観測要求と競合すれば撮られないことがあります[13]。

**新規撮像**は、これから撮ってもらう注文です。商用の衛星は、利用者の注文で撮る仕組みを持っています。防衛省の研究所が2025年に出した画像購入の仕様書では、新規撮像は撮像日の14日前までに発注し、天候で撮れないときはアーカイブで補う、と決めています[15]。これが実務の形です。新規撮像には、発注から撮影までの時間と、撮れない可能性が付きます。

一方、政府の衛星は、一般の利用者からの個別の観測要求を受け付けないのがふつうです。だいち4号（ALOS-4）も、一般の利用者からの個別観測要求は受け付けず、要望は配布事業者を通じて伝える形です[12]。「衛星に頼めば撮ってくれる」が成り立つのは、商用の衛星だけと考えます。

## 利用条件：誰が、何に、どこまで使えるか

価格の次に見るのが利用条件（ライセンス）です。読まずに買うと、翌年に使えない、顧客に渡せない、といった手戻りが起きます。

（ここに図：license　買う前に確かめる4つの条件）

**使う人の範囲。** 1つの組織の中で何人でも使えるのか、特定の部署だけなのか、顧客にも渡せるのかが条件で決まります。2011年の調査は、衛星データは1組織ライセンスで組織内の複数の人が使えることが多い、と報告しています[14]。自治体の仕様書には、県と市町村、森林組合連合会が使える「グループ形態のライセンス」を指定した例があります[16]。

**使う目的の範囲。** 内部で見るだけか、外部に公開するかで条件が変わります[14]。高知県の仕様書は、使用許諾の範囲を県の森林クラウドでの森林分野の利用に限り、利用者ごとに管轄エリアだけと定めています[17]。Tellusの無償データにも、Tellusの環境の中でだけ使えるものがあります[8]。

**外に出せる形。** 画像そのものは渡せなくても、解析結果なら渡せる場合があります。岩手県の仕様書は、元のデータに戻せない形にし、著作権の表記を付けることを条件に、二次的著作物の配布と公開を認めています[16]。発注する側は、顧客に渡したいものが「元画像」なのか「結果の地図」なのかを先に決めます。

**出所の表示。** 無償データでも、出所の表示は要ります。Sentinelは「Copernicus Sentinel data [年]」、改変したときは「Contains modified Copernicus Sentinel data [年]」と書きます[1]。JAXAの無償データは「提供：JAXA」などの表示が要ります[6]。

最後に、日本の法律にも触れておきます。細かく撮れる国内の衛星のデータは、「衛星リモセン法」で取扱いの認定が要る場合があります[18]。対象になるのは分解能の高い記録で、たとえば生データでは光学2m以下、SAR 3m以下といった基準が定められています（2017年11月時点）[18]。海外の衛星のデータを受け取って使うだけなら、この法律の対象ではありません[19]。とくに細かいデータを扱うときは、事業者に該当の有無を聞きます。

## よくある誤解

**誤解1：無償データは質が低い。** 違います。分解能が中くらいなだけで、用途によっては十分です。環境省の地盤沈下のマニュアルは、無償のSentinel-1でも、水準測量との較差の標準偏差が0.3cm程度の結果を載せています[10]。足りないのは「細かさ」と「頼める自由」であって、信頼性ではありません。

**誤解2：データを買えば終わり。** データは材料です。解析する人か会社が要り、結果を現地で確かめる費用もかかります。費用はデータ代、解析、確認の3つに分けて見ます。

**誤解3：衛星はいつでもどこでも撮れる。** 衛星には回ってくる周期があり、光学は雲があると地表が写りません。Sentinel-1の周期は12日（1機あたり）で、2機なら6日です[2]。新規撮像を注文しても、撮れない可能性は残ります[15]。

**誤解4：無償なら何に使ってもよい。** 出所の表示は必要です[1][6]。無償でも、使える環境や目的に条件が付くものがあります[6][8]。

## 実務ではここだけ押さえる

（ここに図：cost　費用を分けて考える3つの項目）

- **アーカイブから始める。** 知りたい場所と時期のデータがあるかを、まず検索します。検索は無料です[10]
- **無償で試してから買う。** Sentinel-1などで使えるかを確かめ、足りない点が分かってから商用を検討します
- **費用は3つに分ける。** データ代、解析、確認。見積もりはこの3つを分けて出してもらいます
- **データ代は「単位」を聞く。** 1シーンか、面積か。アーカイブと新規撮像で違うか
- **利用条件を先に決める。** 誰が使うか、顧客に渡すか、外に公開するか。これを見積もりの条件に書きます

## まとめ

- 衛星データは、無償か商用か、アーカイブか新規撮像かの2つの軸で考えます
- 無償データは、世界中を決まった計画で撮り続けています。過去に遡る用途に強く、撮る場所や時期は頼めません
- 商用データは細かく撮れ、新しく撮る注文もできます。価格は配布事業者が決め、単位と条件を確かめます
- 費用はデータ代だけでなく、解析と確認を足して3つで考えます
- 利用条件は価格と同じくらい大切です。使う人、目的、外に出せる形、出所の表示を買う前に確かめます
