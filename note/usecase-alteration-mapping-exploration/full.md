# 探鉱の候補地を、無償の衛星データ（ASTER）の変質帯の地図で絞る：JOGMECの資源探査の実務に見る、15mと30mの多波長画像で分かることと、2008年以降のデータでは分からないこと

（noteに貼る全文。全部を公開する。図は、サイトの記事の図を使う）

## この記事で分かること

- 資源探査の最初の段階で、多波長の衛星データ（ASTER）から熱水変質帯の分布を地図にし、地質調査を入れる地区を絞る使い方
- 独立行政法人石油天然ガス・金属鉱物資源機構（JOGMEC）が公表している解析の手法と、チリの斑岩銅鉱床での例
- データは無償で手に入る一方、鉱物を見分けるバンドは2008年4月以降の観測が使えないという、2026年時点の限界

## どんな使い方か

金属の鉱床を探す探鉱は、段階を踏んで進みます。最初に広い範囲を概査して有望な地区を絞り、次に地質調査、地化学調査、物理探査で候補を詰め、最後にボーリングで鉱化を直接確かめます[1]。広い範囲を人が歩いて調べることはできないため、最初の絞り込みに衛星データが使われます。

斑岩銅鉱床（熱水でできる、品位は低いが規模の大きい銅の鉱床）の周りには、熱水で岩石が変質した「変質帯」が帯状に分布します[1]。変質帯には、カオリナイトやセリサイトのような粘土鉱物、アルナイト、緑泥石や緑れん石のような鉱物が含まれ、それぞれが短波長赤外の特定の波長を吸収します[1]。多波長の衛星データでこの吸収の違いを捉えると、露出した岩石のどこに、どの種類の変質帯があるかを地図にできます。

ASTERは、米国のTerra衛星に載った日本の経済産業省のセンサで、可視近赤外が15m、短波長赤外が30m、熱赤外が90mの分解能、観測幅は60kmです[2]。可視近赤外のバンド比（バンド2÷バンド1）で鉄酸化物を、短波長赤外のバンド4〜9の合成やバンド比で変質鉱物の違いを捉えます[1]。数値標高モデルを使った地形の解析や、断層や割れ目の向きを示すリニアメントの抽出も、同じ段階で行われます[1]。

## 事例：JOGMECの資源探査での利用（チリの斑岩銅鉱床、本格運用）

JOGMECの資源探査部の担当者は、2012年12月のJAXAのワークショップで、鉱物資源探査における光学センサデータの活用を報告しています[1]。チリで広い範囲のASTERデータを解析し、可視近赤外と短波長赤外の合成画像、バンド比の画像、リニアメントの抽出を組み合わせた例が示されています[1]。

チリのエスコンディーダ鉱山の例では、短波長赤外のバンド比の画像で、酸性から中性の変質帯とプロピライト変質帯（緑泥石や緑れん石を含む、鉱床の外側の変質帯）が色の違いとして現れています[1]。ほかにも、斑岩銅鉱床や高硫化系の銅金鉱床で、可視近赤外の画像と短波長赤外の変質帯の画像を比べた例が挙げられています[1]。

報告は、ASTERの可視近赤外と短波長赤外のデータが熱水性の鉱床の探査に有効で、日本の資源の獲得にも寄与してきたと総括しています[1]。実証ではなく、資源機関の探査の実務として使われてきた手法です。ただし、この報告には、解析で新たに見つけた鉱床の数や、絞り込みの効果を示す数字は載っていません[1]。

## 2026年時点の限界

（ここに図：limits　この使い方の5つの限界）

**短波長赤外は、2008年4月以降の観測が使えない。** 変質鉱物を見分ける短波長赤外のバンド4〜9は、検出器の温度の異常で、2008年4月23日ごろ以降のデータが飽和と縞で使えなくなっています[3]。復旧の試みはすべて失敗し、それ以上の対応は予定されていません[3]。可視近赤外と熱赤外のバンドは、その後も良好な品質で観測を続けています[3]。つまり、変質帯の解析に使えるASTERの短波長赤外のデータは、2000年から2008年の保存画像に限られます。最近の地表の変化（新しい露頭、採掘跡）は、この手法では追えません。

**希土類の鉱物は見分けられない。** JOGMECの報告は、バストネサイトなどの希土類鉱物、炭酸塩岩、ジルコンはASTERの波長では識別できず、ハイパースペクトル（数百の細かい波長帯で観測する方式）のデータが要るとしています[1]。この手法が効くのは、熱水変質を伴う鉱床で、レアアースやリチウムの探査にそのまま使えるわけではありません。

**新しい有望地を見つけるのは、難しくなっている。** 同じ報告は、既知の変質帯をASTERで解析することはできても、新たに有望な変質帯を見つけることは難しいとしています[1]。データは2016年4月から無償で公開され[4]、誰でも同じ解析ができます。他社がすでに解析した範囲で、衛星データだけから差がつく余地は小さいと考えるのが安全です。

**岩石が露出していない所では効かない。** 変質帯の解析は、岩石の表面の反射を見るものです。植生や土壌、雪に覆われた地域では、岩石の情報が届きません。チリの事例地域が乾燥した露岩の多い場所であることは、この条件を示しています【要確認】。

**Terra衛星の運用は、終わりが近い。** Terraは2020年2月に軌道を保つ操作をやめ、観測の時刻が少しずつ早まり、2022年10月に高度を下げています[5]。NASAの計画文書（2022年）では、最大限に延長した場合でも2027年3〜4月に搭載機器の停止と衛星の処置を行う予定とされています[6]。新しい観測は近いうちに止まる前提で、保存画像を使う計画にする必要があります【要確認】。

衛星では分からないこともあります。変質帯があっても、その下に採算の取れる鉱床があるとは限りません。品位、埋蔵量、深さは、地質調査、物理探査、ボーリングで確かめるものです[1]。

## （仮）自社の業務に入れるなら

資源会社や商社の探鉱部門が、権益を取る前の候補地の絞り込みに入れる場合を想定した例です。

（ここに図：flow　探鉱の初期に変質帯の地図を入れる手順）

1. 対象地域の2008年4月以前のASTERの保存画像を探し、雲と雪のない場面を選ぶ。データはNASAの配布サイトから無償で入手できます[4]
2. 対象地域の既知の鉱床の周りで解析の手法を試し、変質帯が既知のとおりに出るかを検証する
3. 鉄酸化物の分布、変質鉱物の分布、リニアメントの図を作る
4. 変質帯が重なる地区、構造の交点に近い地区を候補とし、地質調査と物理探査の範囲を決める
5. 現地で露頭と試料を確かめ、図を更新する。鉱化の確認はボーリングで行う[1]

準備として要るのは、多波長の画像を扱える解析の環境と、大気の影響を補正した画像を作る手順です[1]。解析そのものは専用のソフトで行えますが、変質鉱物の吸収の特徴を読む地質の知識がないと、色の違いを鉱物の違いとして解釈できません。

コンサルタントにとっては、2の検証の設計と、4の候補の優先順位付けが仕事になります。解析の結果を納品して終わりではなく、現地調査の範囲と費用に結び付けるところに価値があります。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| 鉄酸化物の分布図（バンド比） | 地図システムで開ける画像データ | 酸化帯の広がり、候補地区の第一候補 |
| 変質鉱物の分布図（短波長赤外の合成とバンド比） | 同上 | 変質帯の種類と中心、地質調査を入れる地区 |
| リニアメント図と地形の解析図（数値標高モデル） | 同上 | 構造の交点、物理探査の測線の向き |
| 既知の鉱床での検証の結果 | 報告書 | この地域で解析をどの程度信じるか |
| 候補地区の優先順位と現地調査の計画 | 一覧表 | 現地調査の範囲、権益の交渉に入る地区 |

変質帯の地図は「ここに変質帯がある」という情報で、「ここに鉱床がある」という情報ではありません。地図を受け取る側は、既知の鉱床での検証の結果と一緒に読む必要があります。

## 費用の考え方

JOGMECの解析の費用は公開されていません。金額は公開されていません。

費用がかかる所は、次の3つです。

- **データ**：ASTERのデータは2016年4月1日からすべての製品が無償で、295万以上の保存画像が公開されています[4]。データの費用はほぼかかりません
- **解析の人件費**：大気の補正、バンド比の計算、変質鉱物の解釈、リニアメントの抽出にかかる人の時間。ここが費用の中心です
- **現地の検証**：解析で絞った地区の地質調査、試料の分析、物理探査。衛星の解析より桁違いに大きい費用になるのが普通で、絞り込みの目的はこの費用を減らすことにあります【要確認】

無償データで成り立つ使い方です。ただし、使える短波長赤外のデータが2008年以前に限られるため[3]、最近の変化を追う目的には別のデータが要ります。希土類のようにハイパースペクトルが要る対象では、データの費用の考え方が変わります[1]。

## 向いている条件、向いていない条件

（ここに図：scale　変質帯の解析が効く地域から、効きにくい地域まで）

| 観点 | 向いている | 向いていない |
|---|---|---|
| 対象の鉱床 | 斑岩銅鉱床、高硫化系の銅金鉱床など熱水変質を伴うもの | 希土類、リチウムなど変質帯の解析で捉えにくいもの[1] |
| 地表の状態 | 乾燥して岩石が露出している | 植生、土壌、雪に覆われている |
| 検証の手がかり | 既知の鉱床があり、解析を検証できる | 既知の鉱床がなく、色の違いを解釈できない |
| 時期 | 2008年以前の地表で足りる | 最近の変化（採掘跡、新しい露頭）を追いたい |
| 段階 | 権益を取る前の広域の絞り込み | 鉱床の品位や埋蔵量の評価 |

## コンサルタントへの示唆

- **最初に、対象地域の植生と、既知の鉱床の有無を聞く。** 露岩が少ない地域では効かず、既知の鉱床がなければ解析を検証できません。ここで向き不向きがほぼ決まります
- **「衛星で鉱床が見つかる」と言わない。** JOGMECの報告は、ASTERで新たに有望な変質帯を見つけることは難しいとしています[1]。提案では「現地調査の範囲を絞る材料」と書きます
- **データの時期の制約を、先に伝える。** 短波長赤外は2008年4月以降が使えず[3]、Terraの運用も終わりが近い[6]ことを、提案の前提に書きます。最近の変化が要る案件では、別の衛星やハイパースペクトルのデータを検討対象に入れます
