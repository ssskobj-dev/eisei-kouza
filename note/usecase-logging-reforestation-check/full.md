# 伐採跡地と再造林を、1.5mの衛星画像の変化通知で確かめる：53自治体が採用した有償の森林サービスと、無償の仕組みとの分かれ目

（noteに貼る全文。全部を公開する。図は、サイトの記事の図を使う）

## この記事で分かること

- 自治体の林務担当が、伐採跡地と再造林地の変化を衛星データでどう受け取っているか
- 有償の高分解能サービスと、林野庁が無償で配る仕組みの、検出できる大きさと更新の間隔の違い
- 2時期の比較で分かること（どこが変わったか）と、分からないこと（いつ、誰が、植えたか）

## どんな使い方か

戦後に植えられた人工林が伐採の時期を迎え、全国で伐採が進んでいます[1]。森林法の改正で、市町村には、伐採後の状況報告の内容を伐採造林届や各計画と照らし、現地で確かめる仕事が加わりました[1]。伐採の届出は年に数千件になる県もあり、宮崎県では伐採および造林の届出が年間約5,000件です[3]。市町村には、専門の知識と技術を持つ職員が足りず、無届の伐採への対応や、伐採後と再造林後の状況確認に苦労しているとされています[3]。

衛星データを使う方法は、職員が山に行く前に「どこが変わったか」を先に知らせます。2つの時期の衛星画像を比べ、木がなくなった場所（伐採跡地）と、植え直された場所（再造林地）を拾い出し、変化があった場所を通知します[1]。職員は、届出と照らして合わない場所だけ現地に行きます。

（ここに図：split　衛星に任せることと、林務担当が行うこと）

## 事例：株式会社パスコの森林変化情報提供サービス

宇宙航空研究開発機構（JAXA）の事例集に、株式会社パスコの「MiteMiru森林（森林変化情報提供サービス）」が載っています[1]。

- 高分解能の光学衛星SPOT6/7の2時期の画像から、伐採跡地と再造林地の変化を検出し、変化情報を通知します。判読にはAIを使っています
- 成果は一般的なWebブラウザで見られ、GISソフトは不要です。登記所備付地図も載せており、地上設置型の太陽光パネルの検出もできます
- サービス開始以降、2024年10月時点で53の自治体が採用しています

林野庁の委託事業でまとめられた、市町村向けの「伐採把握システム利用の手引き」（2023年3月）にも、このサービスが有償のサービスとして載っています[2]。手引きによると、使う衛星はSPOT6/7で分解能は1.5m、森林の専門技術者の判読結果を教師データにAIが伐採跡地を判読し、0.1ha以上の伐採跡地を提供します。図形はシェープファイル形式で、伐採地の面積、撮影時期、2次メッシュ番号が属性として付きます[2]。

自治体が業務として採用している、本格運用の事例です。ただし、事例集には「実証」と「実用」の両方の印があり、どちらに当たるかは明示されていません【要確認】。

## 2026年時点の限界

手引きは、無償の仕組みと並べて、このサービスの性質を書いています[2]。2時期の比較という方法の性質と合わせて整理します。

（ここに図：limits　この使い方の5つの限界）

**更新は不定期で、数か月ごとの確認には向かない。** 手引きは、変化情報の更新頻度が低く不定期のため、数か月ごとの定期的な確認には不向きだとしています[2]。高分解能の衛星は観測の幅が狭く、SPOT6/7の回帰日数は26日です[2]。届出の受付のたびに最新の画像があるとは限りません。

**誤検出がある。** 再現率（見逃しの少なさ）は良好な反面、誤抽出もあり、林地開発の後の太陽光発電用地なども情報に含まれることがあります[2]。抽出された場所には、林地の崩壊や農地への転用など、伐採以外の変化も混じります[2]。

**面積は、現場の実測と一致しない。** 手引きは、抽出した面積は現場の実測と一致しないため、現地確認や衛星画像での確認を勧めています[2]。届出の面積と突き合わせるときは、差の幅を見込みます。

**変化の日付は、2時期の間までしか分からない。** 2枚の画像を比べる方法では、伐採や植栽がその間のいつ行われたかは分かりません【要確認】。届出の「伐採開始の90日前から30日前まで」という期限[2]に合っていたかは、画像だけでは判定できません。

**再造林の検出精度は、公的な検証がない。** 林野庁の委託事業は伐採の把握が対象で、伐採後の造林（再造林）は対象外です[2]。植えた直後の苗木は小さく、衛星画像で植栽の有無を判断するのは難しいと考えられます【要確認】。再造林の通知は、現地確認を減らす材料ではなく、確認に行く順番を決める材料として扱うのが安全です。

物理的に衛星では分からないこともあります。誰が伐採したか、届出の名義と一致するか、植えた樹種、苗木が活着したかは、現地と書類でしか確かめられません。

## （仮）自社の業務に入れるなら

市町村の林務担当が、伐採造林届出の確認業務に入れる場合を想定した例です。手引きが勧める3つの使う場面（届出の受領時、伐採報告の受領時、定期の無届確認）[2]に沿わせます。

（ここに図：flow　届出の確認業務に、衛星の変化通知を入れる手順）

1. 伐採造林届出の範囲を、地図データ（図形）にして持つ
2. 衛星の変化情報（伐採跡地、再造林地）をブラウザまたはシェープファイルで受け取る
3. 届出の範囲、保安林、森林経営計画、林地開発許可の区域と重ねる
4. 届出と重ならない伐採、届出より広い伐採、報告のない再造林の場所だけ現地に行く
5. 指導や勧告の要否と、翌年に確かめる場所を決める

準備として要るのは、届出の範囲の地図データと、保安林や林地開発許可の区域のデータです。手引きは、他の手続きによる伐採と区別するために、これらを重ねることを勧めています[2]。届出が地番の単位で、図形になっていない自治体は、ここから始めます。

コンサルタントや地場の測量会社にとっては、1の届出の図形化と、3の重ね合わせの仕組み、4の現地確認の優先順位の設計が仕事になります。

## 意思決定に使えるデータ

| 受け取るもの | 形式 | 決められること |
|---|---|---|
| 伐採跡地の図形と面積、撮影時期 | ブラウザの表示、シェープファイル[2] | 届出と重ならない伐採（無届の候補）、届出より広い伐採 |
| 再造林地の図形 | 同上 | 造林の状況報告が出ていない場所、現地で確かめる順番 |
| 変化の前後の画像 | ブラウザの表示 | 現地に行く前に、見間違いかどうかを確かめる |
| 届出との照合の結果 | 自治体が記録 | 指導や勧告の要否、翌年の確認対象 |

無届の候補は「候補」です。手引きは、抽出結果に伐採以外の変化が混じることを前提に、現地や画像での確認を求めています[2]。所有者に連絡する前に、前後の画像を見て、保安林や許可済みの区域と重なっていないかを確かめます。

## 費用の考え方

このサービスの利用料は公開されていません。有償のサービスで、有償の高分解能画像を使う構成です[2]。無償データだけの構成ではありません。

公開されている関連の金額として、宮崎県の森林情報のデジタル化の事業があります。県は「森林変化情報サービス用ライセンス」を40本購入し、AI判読用のデータを集めました。事業費は14,948千円（全額が森林環境譲与税）で、微地形表現図の作成なども含む事業全体の額です[3]。資料には事業者名が書かれていないため、この記事の事例と同じサービスかは確かめられていません【要確認】。

費用がかかる所は、次の4つです。

- **サービスの利用料**：画像と解析が含まれます。金額は公開されていません
- **届出の図形化**：届出の範囲を地図データにする作業。初年度に職員または委託の時間としてかかる
- **現地確認**：なくならない。候補の数だけ山に行く時間が残る
- **区域データの整備**：保安林と国有林の区域は国土数値情報から無償で入手できます[2]

無償で成り立たせる道もあります。林野庁の仕組み（FAMOST）は無償の衛星データ（Sentinel-2、約10m）を使い、最小検出面積は0.25haから選びます[2]。有償サービスの1.5mと0.1haに比べると小さな伐採は拾えませんが、まず無償で全域を見て、届出の多い地域だけ有償に切り替える段取りも考えられます。無償の仕組みの詳しい使い方は、関連する記事の「届出のない伐採を、2時期の衛星画像で見つける」にまとめています。

## 向いている条件、向いていない条件

（ここに図：scale　この使い方が効く条件の目安）

| 観点 | 向いている | 向いていない |
|---|---|---|
| 届出の数 | 年に数百件以上で、全部は現地に行けない | 数十件で、全部見て回れる |
| 伐採の大きさ | 0.1ha程度の小さな伐採も拾いたい | 0.25ha以上で足りる（無償の仕組みで間に合う） |
| 確認の頻度 | 年に1〜2回、まとめて照らす | 数か月ごとに新しい変化を知りたい[2] |
| 確かめたいこと | どこが伐られ、どこに植えられたか | いつ伐られたか、苗木が活着したか |
| 体制 | GISがなく、ブラウザで見たい | GISで自前の解析を重ねたい |

## コンサルタントへの示唆

- **最初に、届出の件数と図形化の状況を聞く。** 効果は、届出と重ねられるかで決まります。届出が地番の文字だけなら、図形化の費用と時間を先に見積もります
- **「無届の伐採が分かる」と言わない。** 出てくるのは候補です。誤検出と、伐採以外の変化が混じることを、提案の段階で書きます
- **無償の仕組みと並べて出す。** 1.5mと0.1haの有償サービスと、約10mと0.25haの無償の仕組みを、届出の規模に合わせて使い分ける案にします。再造林の確認は、有償サービスでも現地確認の順番付けまでと位置づけます
