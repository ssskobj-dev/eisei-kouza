# AIが書いた衛星データの解析コード、全部は読めない。5つの塊に分けて境目だけ見る

（note用の下書き。見出し画像は thumbnail.png、図は fig-1.png と fig-2.png を使う。末尾のリンクを公開先のアドレスに直す）

AIに衛星データの解析コードを頼むと、数十行が返ってきます。コードを書けない自分に、これを確かめられるのか。「正しいか確認して」と聞くと、AIは「正しいです」と答えます。これで足りるのか。答えは、全部を読まなくてよい、です。

## コードは5つの塊でできている

（ここに fig-1.png）

衛星データの解析コードは、長く見えても、やっていることは5つです。データを**取る**、使う画素を**選ぶ**、値を**計算する**、区画や期間で**まとめる**、表や地図に**出す**。どの衛星でも、どの指数でも、この順番は変わりません。

塊に分けると、見る場所が決まります。誤りの多くは、塊の中ではなく、塊の境目で起きます。取った値の倍率が違うまま計算に渡す。選んで除いたつもりの画素が、まとめる段で平均に混ざる。境目の数行を見るだけで、大きな誤りの大半は拾えます。

## AIは、別の衛星の決まりを自信をもって混ぜる

たとえば、光学衛星Sentinel-2のLevel-2A（大気の影響を補正した地表の反射率）では、画素の値に波長帯ごとの「ずらし」を足し、倍率の10000で割ると反射率になります。一方、Landsat 8と9のCollection 2 Level-2では、画素の値に0.0000275を掛けて0.2を引きます。衛星が違えば決まりが違います。

AIは「Level-2Aの反射率は、画素の値に0.0000275を掛けて0.2を引いて求めます」と、Landsatの決まりをSentinel-2に当てて、自信のある口調で説明することがあります。コードは止まりません。表はできて、地図も描けます。ただ、森がため池より低く出ます。

## 「正しい？」と聞かない。「何を入れて何を出すか」と聞く

（ここに fig-2.png）

手順は4つです。コードを5つに区切る。塊の境目の行を、AIに「何を入れて何を出すか」1行ずつ説明させる。説明に出てきた数字と名前（倍率、ずらし、分類の番号）を、公式資料と突き合わせる。最後に、言い回しを変えた同じ指示でもう一度書かせ、2本を突き合わせます。

2本で違う箇所が、AIが補った箇所です。ただし、2本が同じだからといって正しいとは限りません。よくある誤りは、2本とも同じように誤ります。突き合わせは「違う箇所を見つける」手順で、「同じ箇所を信じる」手順ではありません。

## 見られないこと

レビューで言えるのは、「見た観点について誤りがなかった」ことまでです。「コードに誤りがない」とは言えません。見ていない観点は、見ていないと書きます。AIの「正しいです」も、人の「見ました」も、どの観点を見たかが添えられて初めて意味を持ちます。

## 明日やること

1. 手元のAIのコードを1本選び、「取る、選ぶ、計算する、まとめる、出す」の見出しを付けてみる。付けられない行が、何をしているか分からない行です
2. 反射率に直す行を探し、使っている倍率とずらしを書き出す。それが、使っている衛星の公式資料と合うかを自分で開いて確かめる
3. 除いた画素を「0」にしていないかを見る。0は「値がない」ではなく「値が0」です

本編では、12項目の共通のレビュー観点の表（どの塊で見るかつき）、レビューのための指示文の例、誤りを3つ仕込んだコードの抜粋と直し方、おかしな結果の例を、公式資料の出典つきで解説しています。衛星データ解析エンジニア 2級の第0部です。
