## LinkedIn

AIに衛星データの解析コードを頼むと、数十行が返ってきます。コードを書けない担当者が、これをどこまで確かめられるか。学習プログラム（衛星データ解析エンジニア 2級）の第0部の章では、「全部を読まずに確かめる」型を整理しました。

コードは、データを取る、画素を選ぶ、値を計算する、区画でまとめる、表に出すの5つの塊でできています。誤りの多くは塊の境目で起きます。取った値の倍率が違うまま計算に渡す。除いたつもりの画素が平均に混ざる。境目の数行を見れば、大きな誤りの大半は拾えます。

AIは、別の衛星の決まりを自信をもって混ぜます。Sentinel-2のLevel-2Aは、画素の値にずらしを足して10000で割ると反射率になります。Landsat 8と9のCollection 2 Level-2は、0.0000275を掛けて0.2を引きます。AIがLandsatの決まりをSentinel-2に当てても、コードは止まらず、地図も描けます。ただ、森がため池より低く出ます。

だから「正しい？」とは聞きません。「何を入れて何を出すか」「どの資料で確かめたか」と聞き、答えの数字を公式資料と突き合わせます。言い回しを変えてもう一度書かせ、違う箇所を見つけます。ただし、2本が同じでも正しいとは限りません。

解析を内製したい会社の担当者、技術者、研究者の方に。
